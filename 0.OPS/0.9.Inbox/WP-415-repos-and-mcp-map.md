# Как получить доступ к репозиториям: через поиск знаний или через клон

> **Про то, где именно лежит каждый репозиторий (какая организация, приватный/публичный) — см. `WP-415-migration-plan.md § Репозитории: где сейчас и где будут`.** Этот документ - только про способ доступа (искать через инструмент или клонировать к себе), эта часть не меняется от переноса репозиториев между организациями.

---

## Принцип

Есть два способа работать с репозиторием:

| Способ | Кому нужен | Как работает |
|-----|-----------|-------------|
| **Поиск знаний (Aisystant MCP)** | Всем (и людям, и облачным помощникам) | Содержимое проиндексировано, ищется через инструмент поиска - клонировать не нужно |
| **Локальный клон** | Разработчикам с VS Code | Нужен для написания кода, коммитов, отладки |

Правило: если ты **читаешь знание** из репозитория - используй поиск. Если **пишешь код** в репозиторий - клонируй локально.

Подключение к поиску знаний - один общий адрес для всех репозиториев, вход через единый вход (OAuth).

---

## Разграничение по роли в команде: что клонировать локально

| Роль | Обязательно клонировать локально |
|------|----------------------------------|
| Разработчик MCP-сервисов | шлюз, поиск знаний, приём событий + нужный сервис |
| Разработчик бота | бот, сборщик событий, обработчик проекций |
| Разработчик фронтенда | веб-интерфейс, сервис профиля пользователя |
| Инфраструктура / БД | репозиторий миграций базы данных (обязательно всем, кто меняет схему) |
| Все разработчики | репозиторий описания экосистемы (для навигации по устройству системы) + канон платформы (через поиск знаний, не клон) |
