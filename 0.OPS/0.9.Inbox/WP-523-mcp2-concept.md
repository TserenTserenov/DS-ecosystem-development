# WP-523: Концепция использования MCP2.0

> **РП:** [WP-523](https://github.com/TserenTserenov/DS-my-strategy/blob/main/inbox/WP-523/WP-523.md) (DS-my-strategy). Решение утверждено пилотом 11.08.2026, зафиксировано в [DRR](https://github.com/TserenTserenov/DS-my-strategy/blob/main/decisions/2026-08/2026-08-11-wp-523-f3-migratsiya-gateway-mcp-na-mcp2.md).

## Что предлагается

`gateway-mcp` работает на старой спеке MCP (2025-03-26): гонки на Durable Object (WP-490), нестабильные OAuth-сессии (WP-466/479), неточный rate-limit, самодельный async-паттерн вместо протокольной гарантии. Новая спека MCP2.0 (2026-07-28) устраняет эти классы проблем структурно.

По АрхГейту (ЭМОГССБ, сравнение вариантов A/B/C) утверждён **вариант C — поэтапная миграция**, с 4 условиями:
- dual-stack на окно депрекации (обе спеки тулов/тестов/доков одновременно);
- канареечный клиент запускается первым, откат — feature-flag'ом;
- security-чеклист (STRIDE, 5 пунктов);
- **hard gate на старт пилотной миграции:** поддержка MCP2.0 подтверждена хотя бы в одном продакшен-клиенте (не по анонсу вендора — по протокольному smoke-тесту).

Инфраструктурный контекст (12.08): контур делится на «мир» (GKE, ведёт Андрей) и «Россия» (текущая инфраструктура Cloudflare, ведём мы). Решение C и hard gate остаются в силе для российского контура; на GKE — своя траектория миграции.

## Что уже подготовлено

- Мировой опыт + архитектурный аудит `gateway-mcp` против спеки 2026-07-28 — сделаны.
- АрхГейт (профиль ЭМОГССБ, сравнение A/B/C) пройден, вердикт C утверждён пилотом.
- Методология измерения эффекта закрыта: двойная метрика TTFR_core/TTFR_user, p95/p50 без Cloudflare Analytics (client-side + gateway-логи), стратификация по `TokenRefreshCoalescer`.
- Клиентская матрица проверена: **на 12.08.2026 поддержка спеки 2026-07-28 не подтверждена ни в одном прод-клиенте** — hard gate на пилотную миграцию (Ф4) пока не пройден.

## К обсуждению

- Координация протокольной миграции на GKE-контуре — ждём ответа Андрея по срокам переезда MCP-серверов.
- Периодическая проверка клиентской матрицы (раз в 2 недели / при релизе Claude Code) — когда gate откроется, Ф4 запускается отдельным РП вне бюджета WP-523.
