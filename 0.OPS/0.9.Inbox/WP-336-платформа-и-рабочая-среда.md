# WP-336: Платформа Aisystant и рабочая среда

> **Для кого:** команда, архитекторы, новые участники  
> **Цель:** понять границу между платформой и рабочей средой, что где работает и как подключиться

---

## Аналогия — банк

**Платформа Aisystant = банк.** Счёт, программа лояльности, консультант, бонусы. Вы заходите через сайт или приложение.

**Рабочая среда = ваш кошелёк и телефон.** Там вы тратите деньги, пишете заметки, ведёте проекты. Банк начисляет бонусы, но не лезет в ваш телефон.

**Платформа и рабочая среда — разные продукты.** Они разговаривают через договор (API), но каждый живёт сам по себе.

---

## Что есть что

### Платформа Aisystant (assistant.com)

Это сайт и бот. Здесь пользователь регистрируется, учится, видит прогресс.

| Сервис | Что делает |
|---|---|
| **Регистрация и профиль** | Личный кабинет, вход, настройки |
| **Программы обучения** | Марафоны, курсы, траектории |
| **Персональное руководство** | Генерация индивидуального плана и заданий |
| **Прогресс и баллы** | Учёт достижений, начисление бонусов |
| **Наставник и поддержка** | Проверка заданий, ответы на вопросы |
| **Сообщество** | Форум, общение с другими участниками |
| **Расписание и напоминания** | Уроки, дедлайны, уведомления |
| **Тайный репозиторий** | Скрытый Git-репозиторий пользователя. Платформа кладёт туда персональное руководство в виде Markdown-файлов. Пользователь видит его, но пока не управляет структурой |

**Чего НЕТ на платформе:** место для проектов, редактор кода, личная база знаний.

---

### Рабочая среда

Это компьютер пользователя с программами, в которых он работает.

| Сервис | Что делает |
|---|---|
| **Редактор (IDE)** | VS Code, Cursor, NeoVim — где пишется код и тексты |
| **Git + хранилище** | GitHub, Gitea — хранение версий проектов |
| **База знаний** | Obsidian, Notion — заметки, идеи, мысли |
| **ИИ-ассистент** | Claude Code, Cursor AI — помощник прямо в редакторе |
| **Проекты пользователя** | Репозитории, файлы, документы |
| **Персональное руководство** | Файлы с заданиями от платформы, которые приходят в рабочую среду |

**Чего НЕТ в рабочей среде:** регистрация, счётчик баллов, форум, программы обучения как such (они приходят в виде руководства).

## Две реализации рабочей среды

### 1. IWE — наш шаблон

Это готовый «дистрибутив» рабочей среды. Мы его сделали, всё настроили — скачал и работай.

**Что входит:**
- VS Code — редактор
- Git — версионирование
- Obsidian (Vault) — база знаний
- Claude Code CLI — ИИ-ассистент
- Инструкции для ИИ (CLAUDE.md) — кто вы, чем занимаетесь
- Подключение к платформе — получение руководства, отправка прогресса
- Готовая структура папок — проекты, заметки, обучение, архив

**Режимы:**
- **Автономный** — работает без платформы. Просто удобная среда для проектов.
- **Подключенный** — получает руководство от Aisystant, отправляет прогресс.

### 2. Пользовательская рабочая среда

Пользователь берёт свои инструменты (Cursor + Notion + GitLab) и подключает платформу по требованиям.

**Примеры:**
- Cursor + Obsidian + GitHub
- VS Code + Notion + GitLab
- NeoVim + своё ПО

## Требования к рабочей среде

Если пользователь хочет получать сервисы платформы в своей среде — она должна уметь следующее.

### Обязательно

| # | Требование | Пояснение |
|---|---|---|
| 1 | **Хранить проекты в Git** | Всё, что вы делаете — в системе контроля версий. Можно забрать с собой |
| 2 | **Иметь базу знаний** | Место для заметок (Obsidian, Notion, Bear — неважно) |
| 3 | **Получать руководство от платформы** | Возможность записать файлы с заданиями и рекомендациями от Aisystant |
| 4 | **Отправлять события в платформу** | Сообщать: «начал работу», «закончил задачу», «сделал заметку» — для учёта прогресса |
| 5 | **Данные принадлежат вам** | В любой момент можете экспортировать всё и уйти |

### Желательно

| # | Требование | Пояснение |
|---|---|---|
| 6 | **ИИ-ассистент в редакторе** | Claude Code, Cursor, Copilot — чтобы ИИ знал контекст ваших проектов |
| 7 | **Инструкции для ИИ** | Файл, где описано: кто вы, чем занимаетесь, какие правила |

### Не требуется

- ❌ Не нужна регистрация внутри рабочей среды — она есть на платформе
- ❌ Не нужен свой счётчик баллов — он на платформе
- ❌ Не нужен свой форум — сообщество на платформе

## Сервис аренды рабочего места

**Это НЕ IWE.** IWE — шаблон, который вы скачиваете и ставите на свой компьютер. Сервис аренды — это **готовое рабочее место в облаке** для тех, кто не хочет или не умеет ничего настраивать.

**Аналогия:**
- IWE = купить MacBook и поставить macOS
- Сервис аренды = взять MacBook в аренду с уже установленной macOS

**Что входит в аренду:**
- VS Code в браузере (cloud IDE)
- Git-репозиторий на нашем сервере (Gitea)
- Преднастроенный IWE — уже настроен, уже подключен к платформе
- Всё работает сразу после регистрации

**Кому нужен:** пользователям без технических навыков, которые хотят начать работу за 5 минут.

**Кому НЕ нужен:** пользователям, у которых уже есть настроенная среда (Cursor, VS Code и т.д.).

## Как это работает вместе

```
Платформа Aisystant (assistant.com)
├── Генерирует персональное руководство
├── Следит за прогрессом
├── Начисляет баллы
└── Доставляет руководство ────────┐
                                   │
                                   ▼
Рабочая среда (IWE / custom / аренда)
├── Редактор — работа              │
├── База знаний — заметки          │
├── Git — проекты                  │
└── Получает руководство ◄─────────┘
    └── Отправляет события (что сделал) ───────►
```

## Уровни пользователя

<details>
<summary>Т1–Т2: Начинающий</summary>

- Живёт на платформе (сайт, Telegram-бот)
- Рабочей среды нет
- Получает руководство через бота
- Работает с программами обучения напрямую на платформе

</details>

<details>
<summary>Т3: Развивающийся</summary>

- Платформа создаёт **тайный репозиторий** (Git)
- Туда кладёт персональное руководство в виде Markdown-файлов
- Пользователь видит руководство, но пока не управляет структурой
- Это переходный этап: уже Git, но ещё не полноценная рабочая среда

</details>

<details>
<summary>Т4: Продвинутый</summary>

- Имеет **свою рабочую среду** (IWE или custom)
- Полный контроль: проекты, заметки, ИИ-ассистент
- Платформа подключается как внешний сервис: доставляет руководство, собирает прогресс
- Может работать автономно (standalone) или подключенно (connected)

</details>
