# Aisystant: платформа и рабочая среда

## Простая аналогия — банк

| Банк | Платформа Aisystant |
|---|---|
| Счёт, карта, бонусы, программа лояльности | Профиль, прогресс, персональное руководство, сообщество |
| Консультант в отделении | Наставник, поддержка |
| Мобильное приложение | Сайт, Telegram-бот |

| Кошелёк / приложение банка | Рабочая среда |
|---|---|
| Телефон пользователя | Компьютер пользователя |
| Приложение банка на телефоне | VS Code, Obsidian, Git — или наш IWE |

**Главное правило:** банк и кошелёк — это разные вещи. Банк начисляет бонусы, а кошелёк — там, где вы тратите. Платформа даёт руководство и отслеживает прогресс, а рабочая среда — там, где вы работаете.

---

## Платформа Aisystant (assistant.com)

Это сайт и бот, где пользователь регистрируется, учится и развивается.

### Что входит в платформу

| Сервис | Что делает |
|---|---|
| **Регистрация и профиль** | Создание аккаунта, личный кабинет |
| **Программы обучения** | Марафоны, курсы, траектории развития |
| **Персональное руководство** | Генерация индивидуального плана и заданий |
| **Прогресс и баллы** | Учёт достижений, начисление бонусов |
| **Наставник и поддержка** | Проверка заданий, ответы на вопросы |
| **Сообщество** | Форум, чат с другими участниками |
| **Расписание и напоминания** | Уроки, дедлайны, уведомления |
| **Тайный репозиторий (Т3)** | Платформа создаёт скрытый Git-репозиторий и кладёт туда руководство. Пользователь видит его, но пока не управляет структурой |

### Чего НЕТ на платформе

- ❌ Место для ваших проектов и заметок
- ❌ Редактор кода и документов
- ❌ Выполнение программ и скриптов
- ❌ Ваша личная база знаний

## IWE — наша рабочая среда (шаблон)

Это готовый «дистрибутив» рабочего места, который мы даём пользователю на Т4. Всё уже настроено — скачал и работай.

### Что входит в IWE

| Компонент | Что делает |
|---|---|
| **VS Code** | Редактор кода и текстов |
| **Git + GitHub** | Хранение версий проектов |
| **Obsidian (Vault)** | Личная база знаний — заметки, идеи, мысли |
| **ИИ-помощник (Claude Code)** | Умный ассистент прямо в редакторе |
| **Инструкции и правила (CLAUDE.md)** | Памятка для ИИ: кто вы, чем занимаетесь, какие у вас проекты |
| **Подключение к платформе** | Автоматически получаете персональное руководство, отправляете прогресс |
| **Шаблон структуры папок** | Уже организовано: проекты, заметки, обучение, архив |

### Два режима IWE

| Режим | Описание |
|---|---|
| **Автономный** | Работает без платформы. Вы просто используете удобную среду для своих проектов |
| **Подключенный** | Подключён к Aisystant. Получаете руководство, баллы, прогресс — всё в одном месте |

## Другие рабочие среды

Пользователь может не использовать наш IWE, а подключить свою. Это как кошелёк стороннего банка — работает, но по договорённости.

### Примеры альтернатив

| Рабочая среда | Что это |
|---|---|
| **Cursor + Obsidian + GitHub** | Современный редактор с ИИ + заметки + облачное хранилище |
| **VS Code + Notion + GitLab** | Классический редактор + база знаний + свой Git |
| **NeoVim + своё ПО** | Для продвинутых пользователей, которые всё настроили сами |
| **Сервис аренды от нас** | Для тех, кто не хочет ничего настраивать. Мы даём готовый VS Code + Git + IWE в облаке |

## Требования к подключаемой рабочей среде

Если пользователь хочет получать сервисы платформы в своей среде — она должна уметь несколько вещей.

### Обязательно

| Требование | Пояснение |
|---|---|
| **1. Хранить проекты в Git** | Всё, что вы делаете — в системе контроля версий. Можно забрать с собой |
| **2. Иметь базу знаний** | Место для заметок (Obsidian, Notion, Bear — неважно) |
| **3. Получать руководство от платформы** | Возможность записать файлы с заданиями и рекомендациями от Aisystant |
| **4. Отправлять события в платформу** | Сообщать: «начал работу», «закончил задачу», «сделал заметку» — для учёта прогресса |
| **5. Данные принадлежат вам** | В любой момент можете экспортировать всё и уйти |

### Желательно

| Требование | Пояснение |
|---|---|
| **6. ИИ-помощник в редакторе** | Claude Code, Cursor, Copilot — чтобы ИИ знал контекст ваших проектов |
| **7. Инструкции для ИИ** | Файл, где описано: кто вы, чем занимаетесь, какие правила |

### Не требуется

- ❌ Не нужна регистрация внутри рабочей среды — она есть на платформе
- ❌ Не нужен свой счётчик баллов — он на платформе
- ❌ Не нужен свой форум — сообщество на платформе

## Как это работает вместе

```
Платформа Aisystant (assistant.com)
├── Генерирует персональное руководство
├── Следит за прогрессом
├── Начисляет баллы
└── Доставляет руководство ────────┐
                                   │
                                   ▼
Рабочая среда (IWE или ваша)
├── VS Code / Cursor — работа      │
├── Obsidian — заметки             │
├── Git — проекты                  │
└── Получает руководство ◄─────────┘
    └── Отправляет события (что сделал) ───────►
```

### Потоки

1. **Платформа → Рабочая среда:** руководство, задания, обновления знаний
2. **Рабочая среда → Платформа:** события (начал работу, сделал задачу, написал заметку)
3. **Платформа → Пользователь:** баллы, новый уровень, рекомендации

## Уровни пользователя

| Уровень | Где находится пользователь | Рабочая среда |
|---|---|---|
| **Начинающий (T0–T2)** | Только платформа (сайт, бот) | Нет. Получает руководство через бот |
| **Развивающийся (T3)** | Платформа + тайный репозиторий | Есть, но управляется платформой. Пользователь видит руководство в Git, но пока не управляет структурой |
| **Продвинутый (T4)** | Своя рабочая среда (IWE или custom) | Полный контроль. IWE из коробки или своя среда по требованиям. Платформа подключается как сервис |
