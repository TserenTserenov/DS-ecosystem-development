# WP-336: Платформа Aisystant и рабочая среда

> **Для кого:** команда, архитекторы, новые участники  
> **Цель:** понять границу между платформой и рабочей средой, что где работает и как подключиться

---

## Аналогия — банк

**Платформа Aisystant = банк.** Счёт, программа лояльности, консультант, бонусы. Вы заходите через сайт или приложение.

**Рабочая среда = ваш кошелёк и телефон.** Там вы тратите деньги, пишете заметки, ведёте проекты. Банк начисляет бонусы, но не лезет в ваш телефон.

**Платформа и рабочая среда — разные продукты.** Они разговаривают через договор (API), но каждый живёт сам по себе.

---

## Платформа Aisystant

Платформа — это **система**. У неё есть несколько интерфейсов, через которые пользователь с ней взаимодействует.

### Интерфейсы платформы

| Интерфейс | Что это |
|---|---|
| **Сайт assistant.com** | Личный кабинет, программы обучения, прогресс, сообщество |
| **Telegram-бот** | Мобильный доступ: уроки, напоминания, быстрые вопросы |
| **MCP-серверы** | Технический интерфейс для ИИ-ассистентов: доступ к знаниям, прогрессу, гайдам |

**Что делает платформа:** регистрация, обучение, прогресс, баллы, сообщество, персональное руководство.

**Чего НЕ делает платформа:** не редактирует ваши файлы, не хранит ваши проекты, не заменяет ваш редактор.

---

## Рабочая среда

Рабочая среда — это **компьютер пользователя** с программами, в которых он работает: пишет код, ведёт заметки, развивает проекты.

Пользователь может использовать **нашу систему IWE** или **свои инструменты**.

---

<details>
<summary><b>IWE — система организации работы</b></summary>

IWE (Intellectual Work Environment) — это **система**, которая описывает, как организовать интеллектуальную работу. Она отвечает на вопросы:

- Как структурировать заметки и проекты?
- Как работать с ИИ-ассистентом?
- Как фиксировать знания?
- Как вести проекты от идеи до результата?

### Шаблон IWE

**FMT-exocortex-template** — это **шаблон**, описывающий систему IWE. Он говорит: «создайте такие папки, используйте такие протоколы, настройте ИИ вот так».

### Инструменты для IWE

IWE работает поверх инструментов, которые пользователь устанавливает сам или получает через сервис аренды:

| Инструмент | Роль в IWE |
|---|---|
| **VS Code / Cursor** | Редактор — где пишутся код и тексты |
| **Obsidian (Vault)** | База знаний — заметки, идеи, мысли |
| **Git + GitHub / Gitea** | Версионирование — хранение истории проектов |
| **Claude Code CLI** | ИИ-ассистент — помощник прямо в редакторе |

**Важно:** VS Code, Obsidian, Git — это **инструменты**, а не части IWE. IWE — это **система**, которая описывает, как с ними работать.

### Режимы IWE

- **Автономный** — пользователь использует систему IWE без подключения к платформе Aisystant. Просто удобный способ организовать работу.
- **Подключенный** — IWE связан с платформой: получает персональное руководство, отправляет прогресс, участвует в программах обучения.

</details>

---

<details>
<summary><b>Пользовательская рабочая среда</b></summary>

Пользователь может не использовать систему IWE, а работать в своей привычной среде. Платформа подключается к ней по требованиям.

**Примеры:**
- Cursor + Notion + GitLab
- VS Code + Obsidian + GitHub
- NeoVim + своё ПО

</details>

| | Платформа Aisystant | Рабочая среда (IWE или custom) |

| **Фронтенд** | Next.js / React (Web), Telegram Bot | VS Code, Obsidian, браузер |

| **Хранилище** | Облако (GKE / VK Cloud) | Локальный диск + GitHub / Gitea |
| **Платежи** | Stripe / YooKassa | — |
| **События** | Activity Hub (event sourcing) | Git-commits, заметки, сессии |
| **Доставка контента** | Генерация + push в Git / MCP | Получение + исполнение |

</details>

<details>
<summary><b>Требования к рабочей среде</b></summary>

Если пользователь хочет получать сервисы платформы в своей среде — она должна уметь следующее.

### Обязательно

| # | Требование | Пояснение |
|---|---|---|
| 1 | **Экспорт данных за 1 действие** | Данные хранятся в формате, из которого можно экспортировать всё за 1 действие — Git, Markdown-архив, или API Notion с экспортом. Можно забрать с собой |
| 2 | **Иметь базу знаний** | Место для заметок (Obsidian, Notion, Bear — неважно) |
| 3 | **Получать руководство от платформы** | Возможность записать файлы с заданиями и рекомендациями от Aisystant |
| 4 | **Отправлять события в платформу** | Сообщать: «начал работу», «закончил задачу», «сделал заметку» — для учёта прогресса |
| 5 | **Данные принадлежат вам** | В любой момент можете экспортировать всё и уйти |

### Желательно

| # | Требование | Пояснение |
|---|---|---|
| 6 | **ИИ-ассистент в редакторе** | Claude Code, Cursor, Copilot — чтобы ИИ знал контекст ваших проектов |
| 7 | **Инструкции для ИИ** | Файл, где описано: кто вы, чем занимаетесь, какие правила |

### Не требуется

- ❌ Не нужна регистрация внутри рабочей среды — она есть на платформе
- ❌ Не нужен свой счётчик баллов — он на платформе
- ❌ Не нужен свой форум — сообщество на платформе

</details>

<details>
<summary><b>Сервис аренды рабочего места</b></summary>

**Это НЕ IWE.** IWE — система организации работы. Сервис аренды — это **готовое рабочее место в облаке** для тех, кто не хочет или не умеет ничего настраивать.

**Аналогия:**
- IWE = методика ведения заметок (как Bullet Journal)
- Шаблон = готовый блокнот с разметкой
- Сервис аренды = взять ноутбук в аренду с уже установленными программами

**Что входит в аренду:**
- VS Code в браузере (cloud IDE)
- Git-репозиторий на нашем сервере (Gitea)
- Преднастроенная среда по системе IWE — уже настроена, уже подключена к платформе
- Всё работает сразу после регистрации

**Кому нужен:** пользователям без технических навыков, которые хотят начать работу за 5 минут.

**Кому НЕ нужен:** пользователям, у которых уже есть настроенная среда (Cursor, VS Code и т.д.).

</details>

<details>
<summary><b>Как выглядит преднастроенная среда в облаке</b></summary>

Пользователь заходит в браузер и видит рабочее место, которое уже настроено по системе IWE.

### Интерфейс

```
┌─────────────────────────────────────────┐
│  Вкладки: Проекты | Заметки | Руководство │
├─────────────────────────────────────────┤
│  📁 Проекты              │  📝 Редактор   │
│  ├── Марафон            │                │
│  ├── Личный проект      │  Тут вы пишете │
│  └── Архив              │  код и тексты  │
│                         │                │
│  📚 Заметки             ├────────────────┤
│  ├── Идеи               │  🤖 ИИ-ассистент│
│  ├── Встреча 26.05      │  Чем могу помочь?│
│  └── Книги              │                │
│                         │                │
│  📋 Руководство (от     │                │
│     платформы)          │                │
│  ├── Урок 1.md          │                │
│  └── Задание.md         │                │
├─────────────────────────┴────────────────┤
│  💻 Терминал  |  🔄 Git (автокоммиты)     │
└─────────────────────────────────────────┘
```

### Что уже настроено

| Компонент | Как выглядит для пользователя | Как работает под капотом |
|---|---|---|
| **Редактор** | VS Code в браузере | Cloud IDE (code-server / VS Code Server) |
| **Проекты** | Папки с файлами | Git-репозиторий на нашем сервере (Gitea) |
| **Заметки** | Вкладка «Заметки» с поиском | Obsidian-like интерфейс или встроенные Markdown-файлы |
| **Руководство** | Вкладка «Руководство» с файлами от платформы | Git-пуш из платформы в репозиторий пользователя |
| **ИИ-ассистент** | Чат справа | Claude Code CLI или API, подключённый к проекту |
| **Терминал** | Панель внизу | Контейнер с Linux, изолированный от других пользователей |
| **Git** | Не видно явно | Автокоммиты при сохранении; пользователь может не знать про Git |

### Что пользователь НЕ делает

- ❌ Не устанавливает VS Code
- ❌ Не настраивает Git
- ❌ Не клонирует репозитории
- ❌ Не пишет конфиги

### Что пользователь делает

- ✅ Заходит в браузер
- ✅ Работает в редакторе
- ✅ Пишет заметки
- ✅ Получает руководство от платформы
- ✅ При желании — форкает репозиторий и уходит на свой GitHub

</details>

## Уровни пользователя

<details>
<summary>Т1–Т2: Начинающий</summary>

- Живёт на платформе (сайт, Telegram-бот)
- Рабочей среды нет
- Получает материалы марафона/программы через веб и бота
- Работает с программами обучения напрямую на платформе

</details>

<details>
<summary>Т3: Развивающийся</summary>

- Платформа создаёт **тайный репозиторий** (Git)
- Туда кладёт персональное руководство в виде Markdown-файлов
- Пользователь видит руководство, но пока не управляет структурой
- Это переходный этап: уже Git, но ещё не полноценная рабочая среда

</details>

<details>
<summary>Т4: Продвинутый</summary>

- Имеет **свою рабочую среду** (по системе IWE или свою)
- Полный контроль: проекты, заметки, ИИ-ассистент
- Платформа подключается как внешний сервис: доставляет руководство, собирает прогресс
- Может работать автономно (standalone) или подключенно (connected)

</details>

## Итого: три продукта

| Продукт | Для кого | Что это |
|---|---|---|
| **Платформа Aisystant** | Все пользователи | Система: сайт, бот, обучение, прогресс, сообщество |
| **IWE (система)** | Технически готовые пользователи | Методология организации работы + шаблон FMT-exocortex-template. Пользователь ставит инструменты сам |
| **Сервис аренды рабочего места** | Новички без технических навыков | Готовое облачное рабочее место — зашёл в браузер и работай. Уже настроено по системе IWE |
