# План миграции репозиториев по организациям (WP-415)

> **Статус: РЕКОМЕНДАЦИЯ к обсуждению.** Исполнение (перенос/создание орг) — необратимое архитектурное действие → перед стартом ArchGate + ратификация с Андреем/Решатом. Источник модели: концепция `WP-415-russia-world-split-concept.md` §1a/§1b + блок «Топология платформ + порядок миграции».

## Поправка к premise

«Перенести всё русское из `aisystant` в `mimsys`» — неточно по двум причинам:

1. **В `aisystant` сейчас всего 4 репо** (сверка `git remote` 13 июня): `PACK-personal`, `DS-ecosystem-development`, `DS-principles-curriculum`, `docs`. Основной канон знания (паки) лежит под личным аккаунтом `TserenTserenov`. Реальная миграция = консолидация канона из **личного + aisystant** в `mimsys`, не только из aisystant.
2. **Не всё едет в `mimsys`.** По юрисдикции делим только **канон знания** (паки). Продукт → `iwesys`; руководства → гайд-орги; личное/секреты/governance → остаются. «Русское» ≠ «в mimsys».

## Порядок действий (sequencing)

1. **Ратификация модели** (Андрей/Решат): топология орг + стратегический вопрос ниже. До этого — не исполнять.
2. **ArchGate** на миграцию (необратимое архитектурное действие): профиль ЭМОГССБ.
3. **Создать организации:** `mimsys`, `mim-guides`, `aisystant-guides` (проверить занятость имён). `iwesys` уже создан.
4. **Сверка с Track B** (WP-285): Паша уже создал отдельную орг под инфру Track B (`gcp-infrastructure`) — не пересекается ли со счётом орг? Уточнить до создания.
5. **Перенести канон знания** (паки из чёткого списка) → `mimsys` (GitHub transfer, по одному, с редиректом). После каждого: переклонить локально, обновить cross-ссылки + конфиг индексации платформы.
6. **Перенести руководства** (`docs`) → гайд-орги.
7. **Решить граничные случаи** (таблица выше) → перенести по решению.
8. **Конвейер канона** `mimsys`→`aisystant` (перевод EN-проекций) — отдельная разработка (НЕ конвейер шаблона iwesys).
9. **Продукт в `iwesys`** (Шаблон/шлюз/s2r) — по сигналу «переноси»; параметризация шаблона + конвейер текстов среды.
10. **Публичный запуск `iwesys`** — после готовности EN-ядра канона в `aisystant`.

## Стратегический вопрос для ратификации (важно)

Перенос RU-источника канона в `mimsys` делает **российскую организацию домом источника знания мирового продукта**. Это операционный выбор (авторы пишут по-русски, русский дом команды), не требование закона о данных (канон ≠ персональные данные). Но у него есть последствие по **владению интеллектуальной собственностью**: где живёт source-of-truth знания и кто им владеет. Вынести на Андрея/Решата явно — возможно, для мирового продукта канон-источник стоит держать в нейтральном/мировом контуре, а не в российском ИП.

## Чего НЕ делаем сейчас

- Не создаём орги, не переносим репо (ждёт ратификации + ArchGate).
- Не переименовываем `aisystant` (вариант 5 отклонён — рвёт бренд).
- Не переносим Шаблон в `iwesys` (ждёт «переноси»).
