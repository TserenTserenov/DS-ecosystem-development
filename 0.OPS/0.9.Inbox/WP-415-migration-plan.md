# План миграции репозиториев по организациям (WP-415)

## Поправка к premise

«Перенести всё русское из `aisystant` в `mimsys`» — неточно по двум причинам:

1. **В `aisystant` сейчас всего 4 репо** (сверка `git remote` 13 июня): `PACK-personal`, `DS-ecosystem-development`, `DS-principles-curriculum`, `docs`. Основной канон знания (паки) лежит под личным аккаунтом `TserenTserenov`. Реальная миграция = консолидация канона из **личного + aisystant** в `mimsys`, не только из aisystant.
2. **Не всё едет в `mimsys`.** По юрисдикции делим только **канон знания** (паки). Продукт → `iwesys`; руководства → гайд-орги; личное/секреты/governance → остаются. «Русское» ≠ «в mimsys».

## Перенос репозиториев без следов

Для мировой инфраструктуры не оставляем редиректов и не используем GitHub transfer. Процесс для одного репо:

1. Создать новое пустое репо в целевой организации (`new-org/repo`).
2. В локальной копии репо открыть `.git/config`.
3. Найти строку remote origin, например `url = git@github.com:aisystant/repo.git`, и заменить `aisystant` на `new-org`.
4. Выполнить `git push -u origin main` (или нужную ветку).
5. Проверить, что в `new-org/repo` появился весь контент и история коммитов.
6. Удалить старое репо в `aisystant`.

1. **Предусловие выполнено:** мировое юрлицо — **Aisystant Corp** (Delaware, уже создано, решение Р-14-9) — владеет мировыми орг/инфрой. Отдельной задачи на оформление нет.

6. **Консолидировать канон-источник в мировом контуре** (паки из чёткого списка) → мировая канон-орг (GitHub transfer, по одному, с редиректом). `PACK-personal` уже в мировом aisystant. После каждого: переклонить локально, обновить cross-ссылки + конфиг индексации платформы.

## Стратегический вопрос — РЕШЁН принципом 5a

Где живёт source-of-truth канона и кто им владеет — **решено директивой пилота:** канон-источник в **мировом** контуре, дом — `aisystant`, владение Aisystant Corp; российская организация НЕ может быть домом источника знания (иначе мир зависит от России). Остаточных под-вопросов нет.

- Не переносим канон в `mimsys` (нарушает принцип независимости 5a).
