# WP-281: Track A — Переход на новую архитектуру

> **Контекст:** Ильшат принимает российскую инфраструктуру (Track A). Церен уходит на Track B. План — передача + развитие: устранение LMS-монолита, выделение платёжного блока, масштабирование на 2000 подписчиков.
>
> **Принцип:** Каждую неделю Ильшат берёт на себя новую зону. Сроки сжаты в 2 раза — автономия к 15 июля.

---

## Итоговый результат: платформа на 2000 подписчиков

Track A должен уметь к 15 июля:

| # | Функция | Что это даёт |
|---|---------|--------------|
| 1 | **Единый реестр оплат** — все 8 каналов в Neon, LMS читает, не пишет | Нет потерянных платежей, маркетинг видит полную воронку |
| 2 | **Автодопуск и маршрутка** — оплата → доступ без ручных действий | Масштабирование без роста поддержки |
| 3 | **Программа лояльности** — баллы/бонусы с управлением через Directus | Мотивация, удержание, реферальная механика |
| 4 | **Персональные руководства** — production, UX, managed-канал | Продуктовая ценность для подписчика |
| 5 | **CRM: Metabase + Directus** — маркетинг (Алёна), финансы (Гиляна), операции | Прозрачность без запросов к разработке |
| 6 | **Единая авторизация Ory** — один аккаунт на все сервисы | Упрощение входа, защита данных |
| 7 | **Масштабируемая инфраструктура** — VK Cloud + Kubernetes или закреплённый план | Готовность к росту без аварий |

## Критерии готовности к 2000 подписчикам

| # | Критерий | Как проверить |
|---|----------|---------------|
| K1 | Оплата → доступ ≤ 2 минут без ручных действий | Тестовый платёж по каждому каналу |
| K2 | Поддержка видит полную историю платежей в Directus | Запрос от подписчика → найден за < 1 мин |
| K3 | Маркетинг строит воронку без запроса к разработке | Алёна делает дашборд сама |
| K4 | Финансы сверяют выручку без участия Димы | Гиляна сверяет каналы в Metabase |
| K5 | Баллы/бонусы начисляются автоматически, конфиг меняется через Directus | Изменение курса → видно в боте за < 5 мин |
| K6 | Персональные руководства работают в production | 50+ пилотов с руководствами |
| K7 | Инфраструктура выдерживает 10× текущей нагрузки | Load-test или оценка ресурсов |
