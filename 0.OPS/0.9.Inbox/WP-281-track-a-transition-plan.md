# WP-281: Track A — Переход на новую архитектуру

> **Контекст:** Ильшат принимает российскую инфраструктуру (Track A). Церен помогает как разработчик по Track A и Track B. План — передача + развитие: устранение LMS-монолита, выделение платёжного блока, масштабирование на 2000 подписчиков.
>
> **Принцип:** Каждую неделю Ильшат берёт на себя новую зону.

---

## Итоговый результат: платформа на 2000 подписчиков

Track A должен уметь к 15 июля:

| # | Функция | Что это даёт |
|---|---------|--------------|
| 1 | **Единый реестр оплат** — все 8 каналов в Neon, LMS читает, не пишет | Нет потерянных платежей, маркетинг видит полную воронку |
| 2 | **Автодопуск и маршрутка** — оплата → доступ без ручных действий, кик неоплативших | Масштабирование без роста поддержки |
| 3 | **Программа лояльности** — баллы/бонусы, управление через Directus, реферальная механика | Мотивация, удержание |
| 4 | **Персональные руководства + CI/CD** — production: universal + personal, доставка релизов автоматически | Продуктовая ценность, скорость обновлений |
| 5 | **IWE для пользователей** — бот Aist, onboarding T1→T4, граф понятий, экзокортекс, MCP Gateway | Полноценная среда роста |
| 6 | **CRM: Metabase + Directus** — Алёна (маркетинг), Гиляна (финансы), Ильшат (операции) | Прозрачность без запросов к разработке |
| 7 | **Единая авторизация Ory** — один аккаунт: бот, руководства, Directus, клуб | Упрощение входа, защита данных |
| 8 | **Поддержка и обратная связь** — тикеты, автоклассификация, FAQ-обновления | Качество сервиса при росте |
| 9 | **Масштабируемая инфраструктура** — выдерживает 2000 подписчиков: VK Cloud K8s или закреплённый план | Готовность к росту без аварий |

## Критерии готовности к 2000 подписчиков

| # | Критерий | Как проверить |
|---|----------|---------------|
| K1 | Оплата → доступ ≤ 2 минут без ручных действий | Тестовый платёж по каждому каналу |
| K2 | Поддержка видит полную историю платежей в Directus | Запрос от подписчика → найден за < 1 мин |
| K3 | Маркетинг строит воронку без запроса к разработке | Алёна делает дашборд сама |
| K4 | Финансы сверяют выручку без участия Димы | Гиляна сверяет каналы в Metabase |
| K5 | Баллы/бонусы начисляются автоматически, конфиг меняется через Directus | Изменение курса → видно в боте за < 5 мин |
| K6 | Персональные руководства работают в production, обновляются через CI/CD | 50+ пилотов с руководствами |
| K7 | IWE onboarding: новый пользователь до первой сессии < 15 мин | Тестовый проход воронки |
| K8 | Инфраструктура выдерживает 10× текущей нагрузки | Load-test или оценка ресурсов |
