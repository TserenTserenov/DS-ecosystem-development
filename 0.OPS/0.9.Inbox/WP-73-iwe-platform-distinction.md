# Различение: Платформа Aisystant ≠ IWE

**IWE** — автономная персональная среда, развёрнутая у пользователя. Подключается к Платформе Aisystant через MCP Gateway для получения сервисов. Базовые функции (редактирование, git, скрипты) работают без подключения.

**Платформа Aisystant** — облачный бэкенд, единый для всех пользователей. Доставляет контент, идентификацию, сервисы сообщества, прогресс.

**Это два разных объекта с явным интерфейсом между ними** (MCP Gateway `mcp.aisystant.com/mcp`).

---

## Сравнительная таблица

| Аспект | IWE | Платформа Aisystant |
|---|---|---|
| **Где живёт** | На стороне пользователя — git-репо, файловая система, VS Code | В облаке — Railway, Neon, CF Workers |
| **Кто владеет** | Пользователь | Aisystant |
| **Что содержит** | CLAUDE.md, memory/, Pack-клоны, DS-репо, локальный контекст | Identity (Ory), данные прогресса (Neon, Слой 2), Knowledge Index, MCP Gateway, биллинг, марафон, когорты |
| **Жизненный цикл** | Эволюционирует с пользователем | Обновляется командой Aisystant централизованно |
| **Обязательность** | Нет — T1–T3 работают без IWE через бот/браузер | Да — базовая инфраструктура |
| **Интерфейс** | MCP-клиент в настройках (потребитель Gateway) | MCP Gateway (единая точка входа для агентов) |
| **Кто разрабатывает** | Тсерен (IWE template) | Андрей (платформа) |
| **Автономность** | Работает офлайн | Требует подключения |

## Правило размещения артефактов

Для пограничных артефактов — вопрос: **«кто управляет этим экземпляром?»**

| Артефакт | Управляет экземпляром | Принадлежность |
|---|---|---|
| Pack-клон | Пользователь (пуллит, форкает, замораживает) | IWE |
| Данные прогресса (cp-профиль, Нeon) | Платформа (вычисляет и хранит) | Платформа |
| memory/ личные файлы | Пользователь | IWE |
| MCP-клиент config | Пользователь (local settings) | IWE |

---

## Интерфейсы: две сущности, не три

Интерфейсы (бот, Web App, браузер, MCP Gateway) — часть платформы, не отдельная сущность.

| Интерфейс | Принадлежность | Примечание |
|---|---|---|
| Telegram-бот | Платформа | |
| Web App, браузер | Платформа | |
| MCP Gateway | Платформа | Единственный контракт с IWE |
| VS Code + Claude Code | Хост Anthropic | Aisystant владеет только Gateway и ответом |
| MCP-клиент config в VS Code | IWE | Настройки пользователя |

---

## Доступ к данным IWE через разные поверхности

| Данные | Бот | Web App / браузер | VS Code |
|---|---|---|---|
| Pack, Knowledge Index | ✅ | ✅ | ✅ |
| Прогресс (cp-профиль, Neon Слой 2) | ✅ | ✅ | ✅ |
| Личные знания L4 (репо, memory/) | 🔶 | 🔶 | ✅ |
| Запись в git-репо пользователя | ❌ | ❌ | ✅ |
| Протоколы, скрипты, хуки | ❌ | ❌ | ✅ |

**Легенда:**
- 🔶 — не реализовано (WP-209); технически возможно через Gateway-инструмент
- ❌ — архитектурно запрещено: сервер Aisystant не имеет прямого доступа к git-репо пользователя (data sovereignty)
