# История изменений модели лояльности IWE (WP-327)

## v4.4 — 2026-05-28

**Источник:** peer-сессия `2026-05-28-07-wp327-v43-review-findings` (Claude + Kimi).
**Что меняет:** фиксация 6 содержательных решений по итогам критического разбора v4.3.

### Решения
1. **Базовый множитель action** 20 → **25**. Cap Мастера: 70 → 88. Реалистичный день Мастера: 516 → ~572 (близко к цели 600).
2. **Реферальный бюджет** §11: формулировка «из реферальной части бюджета» → «пропорционально входящей выручке от приведённого пилота».
3. **§10** упрощено: убран двойной `min()` — баллы → бонусы конверсия 1:1, срез только в §4.
4. **Курс**: верхний потолок остаётся 0.20 (стартовый 0.10 → целевой 0.20 через 1-2 месяца автоматически через EMA). UI коммуницирует «бонусы дорожают».
5. **Welcome 100 бонусов** (не баллов). Триггер `subscription_first_purchased`. Idempotency по user_id. Не записывается в `earned_total`.
6. **Удалены все исторические упоминания** v4.2 из тела документа (8 мест: §1 антипаттерны, §8, §9, §10, §11, §12, footer-блок «Изменения документа»).

### Технические правки таблиц
- §7 шкала 12 ступеней: action_cap, daily_cap, теор. макс пересчитаны под base=25 и целевой курс 0.20.
- §7 прогноз эмиссии (N=500): пересчитан под новые лимиты, итог ~92 000 бонусов/мес (было 74 000).
- §12 примеры: Проактивный и Мастер пересчитаны под base=25.
- §6.5: число отложенных событий уточнено (18, не 16).

## v4.3 — 2026-05-28 (заменён v4.4)

**Источник:** peer-сессии `2026-05-27-14` / `2026-05-27-16` / `2026-05-27-26`.

### Решения
- Курс удвоен (0.05 → 0.10), базовый множитель уменьшен в 10 раз (200 → 20). Совокупный эффект на бюджет сохраняется, но рублёвая ценность бонуса вдвое выше для пилота.
- Калибровочный множитель сохранён равным 8.
- Случайный (ступень 1) больше не получает баллов — коэф. Квалификации = 0 вместо 0.2.
- Мастер усилен — коэф. Квалификации = 3.5 вместо 3.0.
- Серия сокращена до 4 уровней, максимум 28+ дней = ×2.2.
- Тиры с разной максимальной скидкой и месячным лимитом упразднены. Единый механизм для всех ступеней. Бонусы переносятся между месяцами без верхнего потолка.
- Приветственный бонус 100 баллов при первой регистрации (в v4.4 переопределено: 100 бонусов при первой оплате подписки).
- 15 активных событий на старте + 16 отложенных (в v4.4 уточнено: 18 отложенных).
- Сокращение управления: вместо ~25 разнородных параметров — 7 главных ручек + 4 справочника.

### Известные проблемы (исправлены в v4.4)
- §5.1: численные примеры (17.4/27.2/42.5) не соответствовали показателю 0.6 → опечатки.
- §12.2: пример Мастера показывал 560/день, но при корректном применении per-action cap=70 реальная сумма = 516.
- §3 vs §11: противоречие о реферальном бюджете.
- §10 vs §4: двойное применение суточного лимита.
