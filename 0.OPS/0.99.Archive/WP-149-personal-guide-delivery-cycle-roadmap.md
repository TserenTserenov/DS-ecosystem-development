# Дорожная карта цикла доставки персонального руководства

## Модель: три источника → формирование → доставка

Руководство собирается из трёх источников: **Память и Персона** (кто пилот и что делал), **личный IWE** (планы, цели, неудовлетворённости, паки), **универсальные руководства** (пул материалов). Формирование (роль «Портной») - главная функция. Доставка (запись в репозиторий → витрина → уведомление) - завершающая стадия. Витрина (сайт Натальи) - downstream-потребитель, в сам цикл не входит.

## Наложение РП на стадии каскада

| Стадия каскада | Какой РП её закрывает | Состояние |
|----------------|------------------------|-----------|
| **И1** Память и Персона | Схема, оценщик ступени, согласие (РП253); двойник (РП368) | РП368 закрыт; РП253 в работе |
| **И2** Личный IWE | Каскад стратегирования (не РП доставки) | Работает |
| **И3** Универсальные руководства | Контент и кейсы (РП333); разметка (РП364 Ф6) | Обогащение качества, не блокер первой версии |
| **Ф1-Ф3** Формирование (ядро) | Система генерации руководств, Эпоха 1 (РП149) | Заморожен, но разблокирован |
| **Ф4** Расписание недели (путь А) | Новая работа: генератор индекса + спецификация формата | Нет |
| **Д1** Запись в репозиторий | Создатель репо (РП309) + отправка из Портного (РП149, шаг S7) | Создатель готов для одного пилота |
| **Д2** Отображение (витрина) | WP-426 (фронтенд сайта МИМ) + WP-281 (Наталья) + веб-сервис | Сервис готов, фронтенд WP-426 в проектировании |
| **Д3** Уведомление | Telegram-уведомление в Портном | Готово |
| Вход Д2: баллы/бонусы | Новая работа: интерфейс отдачи баллов наружу | Данные есть, интерфейса нет |

## Что нужно Наталье перед стартом (три блокера передачи)

1. **Спецификация формата индекса недели** (путь А: индекс поверх файлов дней) - её ждёт WP-281.
2. **Интерфейс баллов и бонусов** (отдача наружу готовых данных).
3. **Реальные файлы в формате** в репозитории пилота (выход генератора индекса).

## Отложено (не нужно для первой версии)

- Маршрутизация витрины под программы РР/ИР - только если появятся не-ЛР участники.
- Разметка пула под умный подбор (РП364 Ф6) - улучшение качества, версия 2.
