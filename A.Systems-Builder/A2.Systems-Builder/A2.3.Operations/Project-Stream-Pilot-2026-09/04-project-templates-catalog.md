# Каталог шаблонов проектов

> Десять заготовок по трём типам. Каждая - стартовая точка для подгонки под человека, не готовый проект. До распаковки участнику можно показывать только названия-истории («у одних - вечер, у других - деньги, у третьих - непонятно что, и это тоже проект»), без кнопки «выбрать».

## Тип «переход» (из А в Б)

**П1. Вечер, который восстанавливает.** Из «вечер расползается (лента/бокал/поздний отбой)» в «вечерний ритуал восстановления». Практика: фиксированное время + 2-3 элемента ритуала. Ведущий: отметка ритуала. Итоговый: свежие утра за неделю. Пересмотр: два срыва к среде - упростить ритуал, сдвинуть время.

**П2. Первый час - мой.** Из «день начинается с чужих задач» в «первый час на главную задачу». Практика: час без мессенджеров с планом на день. Ведущий: отметка часа. Итоговый: главная задача закрыта 4+ дней. Пересмотр: час не выходит - начать с 25 минут.

**П3. Переход к новой работе.** Из «терплю текущую» в «управляемая воронка по трём моим критериям». Практика: 30-45 минут в день на воронку (критерии → цели → касания). Ведущий: целевые касания за день. Итоговый: воронка со стадиями и первые ответы. Пересмотр: ответов нет к среде - меняем сегмент или подачу, не бросаем. Внимание наставника: оффер - не критерий недели.

**П4. Спорт, который не срывается.** Из «рывками по вдохновению» в «три короткие тренировки в неделю по расписанию». Ведущий: тренировка сделана. Итоговый: неделя без обнуления. Пересмотр: пропуск двух - сократить длительность вдвое, оставить расписание.

**П5. Деньги под присмотром.** Из «утекают незаметно» в «еженедельный обзор трат с одним решением». Практика недели-пробы: ежедневная фиксация трат за 5 минут. Ведущий: фиксация сделана. Итоговый: названы три главные утечки + одно решение. Пересмотр: фиксация не идёт - переключиться на автоимпорт/фото чеков.

## Тип «поддержание» (удержать под нагрузкой)

**П6. Режим сна в период завала.** Практика уже есть - проект в её удержании: отбой в окно ±30 минут при рабочем пике. Ведущий: попадание в окно. Итоговый: сколько ночей из 7 в окне. Пересмотр: окно рвётся - договориться с собой о «минимальной версии» вечера.

**П7. Читаю каждый день.** Удержать 20 минут чтения/языка при загрузке. Ведущий: отметка. Итоговый: дней с практикой из 7. Пересмотр: заменить время дня, связать с существующей привычкой.

## Тип «исследование» (Б неизвестно)

**П8. Куда уходит энергия.** Вопрос недели: «что меня наполняет и что опустошает?» Практика: вечером 3 строки - события дня с оценкой заряда. Итоговый: карта трёх утечек + гипотеза первого перехода (готовый вход в следующий проект).

**П9. Какая траектория моя.** Вопрос недели: «в какой роли я хочу работать?» Практика: один разговор в день с носителем интересной роли (или разбор одной роли по материалам) + дневник реакций. Итоговый: 2-3 гипотезы траектории с критериями проверки.

**П10. Что отдать ИИ первым.** Вопрос недели: «какие мои рутины съедают больше всего?» Практика: фиксация повторяющихся дел по ходу дня. Итоговый: топ-3 кандидата на ИИ-поддержку. Мостик: естественный вход в практикум личного ИИ.

## Как подгонять шаблон (для ведущего и ИИ-помощника)

1. Услышать неудовлетворённость участника (часть 2 записи + распаковка).
2. Сверить зону безопасности по скринингу (03): зелёная - любой шаблон; жёлтая - только в рамках плана специалиста; красная тема в поток не идёт.
3. Выбрать 1-2 ближайших шаблона, показать участнику как примеры «похожих историй».
4. Вместе переписать формулировку под его слова и его масштаб (7 дней!).
5. Прогнать по рубрике наставника (7 проверок) прямо на встрече.
