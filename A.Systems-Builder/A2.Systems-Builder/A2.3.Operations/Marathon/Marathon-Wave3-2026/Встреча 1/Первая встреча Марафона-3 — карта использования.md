# Первая встреча Марафона-3 — карта использования

> Карта отвечает на четыре вопроса пилота: что можно взять в Паки, публикации, программу ЛР и материалы Марафона. Это предложения для приёмки, а не автоматическое внесение в целевые документы. Реплики участников обезличены; публичное использование личных кейсов требует отдельного согласия.

## Главный вывод

Самый сильный новый материал встречи — не отдельная история Земмельвейса: она уже извлекалась в WP-330 по итогам первой волны. Новая ценность находится в связках:

1. `состояние → метод → новое состояние` как способ разбирать работу и отдых;
2. `методы → стиль человека → культура группы → производимые объекты`;
3. собранность как способность возвращаться, а не как отсутствие сбоев;
4. ОРЗ как новый стиль совместной работы человека и ИИ, а не техника написания запросов;
5. минимальный рабочий продукт как свидетельство удержанного внимания.

## 1. Что можно взять в Паки

### Высокий приоритет: дополнить существующие сущности

| Мысль из встречи | Куда направить | Что именно добавить | Почему не новая сущность |
|---|---|---|---|
| Стиль жизни производит желаемые объекты | `PD.PRINC.039 Lifestyle As Method Set` | Причинную цепочку: набор методов → воспроизводимый стиль → поток результатов/объектов. Добавить диагностический вопрос: «Какой стиль регулярно производит этот объект?» | Принцип «стиль как набор методов» уже существует; встреча даёт ясное объяснение причинности |
| Стиль человека и культура группы находятся на разных масштабах одной механики | `PD.FORM.059 Culture As Accepted Methods` | Явную границу масштабов: индивидуально воспроизводимые методы = стиль; группой воспроизводимые методы = культура; окружение переносит методы между уровнями | Определение культуры как принятых методов уже есть |
| Собранность проверяется возвратом после сбоя | `PD.CHR.002 Emotional Stability` | Поведенческие признаки: время до возврата; минимальное действие возврата; обращение за поддержкой вместо исчезновения; сохранение «участия в игре» | Модель неваляшки уже канонизирована; встреча добавляет наблюдаемые сигналы в контексте саморазвития |
| ОРЗ организует совместную систему «человек + ИИ» | `DP.M.003 Context Engineering Protocol` | Популярный пример открытия: назвать роль человека, роль ИИ, метод и продукт; пример закрытия: проверить и сохранить результат. Отдельно подчеркнуть «работа с ИИ ≠ написание промтов» | ОРЗ уже является Pack-методом; нужен образовательный пример, не дубликат метода |
| Отдых оценивается по переходу состояния | `PD.FORM.009 Leisure Classification` и учебный `METHOD.006 Leisure` | Проверку: исходное состояние → метод досуга → фактическое состояние после. Кейс «сериал или прогулка» оставить как сравнение гипотез, не универсальное предписание | Досуг уже формализован; встреча даёт простой системный тест эффективности |

### Средний приоритет: добавить как примеры или свидетельства

- К `PD.METHOD.004 Thinking in Writing` добавить прогулку и мимолётную заметку как связку «фоновая переработка → немедленная фиксация». Не создавать новый метод: мимолётные заметки уже описаны.
- К различению «развитие как стиль жизни ≠ курс» добавить марафонский пример: две недели не завершают развитие, а ставят минимальный повторяемый контур.
- К формализации нарратива четырёх уровней (`PD.FORM.137`) добавить фразу-переход: «от желаемых объектов к стилю, способному их производить».
- К материалу о рабочем продукте добавить допустимый минимальный результат: заметка «ничего не понял, читал это, внимание уходило туда-то». Это показывает, что продукт может фиксировать наблюдение, а не только успешный ответ.

### Пока не переносить без дополнительной сверки

- Различение ролей операционного менеджера, менеджера организационного развития и лидера звучит перспективно, но на встрече не были определены их методы и рабочие продукты. Сначала нужно сверить существующие ролевые паспорта, затем решать, есть ли пробел.
- Утверждение о нежелании работодателей брать возрастных людей нельзя переносить в Pack в прозвучавшей форме: это широкое эмпирическое обобщение без проверки и с риском возрастной дискриминации.
- Карьерный пример «четыре ступени и рост дохода в десять раз» нельзя превращать в причинное обещание программы без документированного кейса.
- Историю Земмельвейса не создавать повторно: она уже вошла в разбор первой волны. Перед публичным использованием отдельно проверить исторические детали.

## 2. Что взять в черновики постов и коротких видео

### Сильные самостоятельные сюжеты

| Сюжет | Основной тезис | Подходящий формат | Визуальный или драматургический ход |
|---|---|---|---|
| Неваляшка | Систематичный человек не тот, кто не падает, а тот, кто умеет возвращаться | Пост + ролик 30–45 секунд | Неваляшку отклоняют, она возвращается; затем три минимальных действия возврата |
| Ясность | Ясность не решает все проблемы, но показывает следующий ход | Пост-карусель + говорящая голова | Экран с десятками задач → четыре вопроса: состояние, роль, метод, продукт |
| Пять минут в плохой день | Пять минут в аврале тренируют внимание сильнее, чем час в идеальную субботу | Короткий ролик | Контраст «идеальный календарь» и реальный день с одним маленьким слотом |
| Стиль производит объекты | Дом, продукт и должность — следствия повторяемого способа действия | Пост-схема + ролик | Стрелка от ежедневных методов к объекту; затем обратный вопрос к зрителю |
| Цель не исполняется | Часто не нужна новая цель — нужен другой портфель методов | Пост с чек-листом | Список целей заменяется инвентаризацией продуктивных и непродуктивных методов |
| Отдых как переход состояния | Не всё, что называется отдыхом, действительно восстанавливает | Пост-эксперимент + ролик | «Устал → сериал → какое состояние?» против «Устал → прогулка → какое состояние?» |
| Работа с ИИ — не промты | Результат создаёт полный контур роли, метода, продукта и закрытия | Серия из 2–3 коротких видео | Плохой сценарий: запрос и потерянный ответ. Хороший: ОРЗ и сохранённый продукт |
| Школа или мастерская | В школе знание можно отложить; в мастерской применение происходит в той же сессии | Пост + ролик | «Посмотрел урок» против «оставил заметку/схему/решение» |
| «Ничего не понял» — тоже продукт | Честная заметка о непонимании лучше исчезновения без следа | Короткий ролик | Пустая страница → одна честная запись → материал для следующего шага |
| Умный старт или длинная дистанция | Быстро понять недостаточно; выигрывает тот, кто дольше остаётся в игре | Пост-история | Две траектории: яркий старт с обрывом и медленный путь с накоплением |
| Мимолётная заметка | Идея часто приходит после чтения, особенно на прогулке; её нужно вынести из головы | Ролик 20–30 секунд | Прогулка → мысль → голосовая заметка → возвращение внимания к прогулке |

### Сюжеты для серии, а не одиночной публикации

Серия «Разбери себя как систему»:

1. Как назвать исходное состояние.
2. Как отличить роль от должности.
3. Как выбрать метод перехода.
4. Как определить минимальный рабочий продукт.
5. Как закрыть сессию и не потерять результат.

Серия «Из чего состоит личная культура»:

1. Автоматические методы, которые уже управляют днём.
2. Почему стратегия проигрывает сложившемуся стилю.
3. Как окружение воспроизводит методы.
4. Как заменить один метод без попытки переделать всю жизнь.

### Что не публиковать без доработки

- Личные описания состояния и работы участников — только после отдельного согласия каждого человека.
- Исторические и спортивные истории — после фактчека первичных источников.
- Категоричные тезисы о возрасте, нейромедиаторах и гарантированном карьерном эффекте.
- Разделение бесплатного и платного участия — только после сверки действующих условий потока.

## 3. Что взять в программу ЛР

### Вводный модуль программы

Добавить компактную причинную карту:

`текущее состояние → роль → метод → рабочий продукт → новое состояние`

Показать её на трёх примерах:

1. саморазвитие: расфокус → роль Ученика → медленное чтение → заметка → большая ясность;
2. отдых: усталость → роль организатора собственного досуга → прогулка → восстановленное состояние;
3. работа с ИИ: неопределённая задача → роли человека и ИИ → ОРЗ → сохранённый продукт → готовность следующего хода.

### Модуль собранности

Усилить модель собранности двумя измерениями:

- удержание внимания в нормальном режиме;
- возвращение внимания после нарушения режима.

В упражнение добавить журнал возвратов: что выбило, сколько времени занял возврат, какой крючок помог, какое минимальное действие подтвердило возвращение. Это делает модель неваляшки наблюдаемой и пригодной для обсуждения с наставником.

### Модуль «Мировоззрение, культура работы и стиль жизни»

Использовать связку из встречи:

- желаемый объект;
- стиль, который способен его производить;
- методы, составляющие стиль;
- культура и окружение, которые поддерживают или подавляют методы.

Упражнение: выбрать один желаемый объект и не строить план достижения, пока не описан производящий его стиль. Затем найти один метод, который уже поддерживает этот стиль, и один автоматизм, который ему мешает.

### Модуль методов

Добавить «аудит портфеля методов» вместо очередного упражнения по целям:

- методы работы;
- методы саморазвития;
- методы отдыха;
- методы формирования окружения;
- методы работы с ИИ;
- продуктивность и цена каждого метода;
- один метод на постановку, один на удаление или ограничение.

### Модуль досуга

Добавить эксперимент «метод отдыха как гипотеза перехода состояния». Участник фиксирует состояние до, выбранный метод и состояние после. Через неделю сравнивает субъективно называемый отдых с реально восстанавливающими практиками.

### Модуль работы с ИИ

Использовать тезис «стиль работы с ИИ — не умение писать промты». Дать практику совместной сессии:

1. назвать роль человека и границу его ответственности;
2. назвать роль ИИ;
3. определить метод и продукт;
4. выполнить работу;
5. проверить, сохранить и закрыть.

### Наставнические материалы

Включить протокол работы с выпадением:

1. не оценивать участника по факту пропуска;
2. локализовать место потери внимания;
3. выбрать один крючок возврата;
4. уменьшить действие до выполнимого;
5. получить видимое свидетельство возврата;
6. позже разобрать, выдерживает ли метод реальную неделю.

## 4. Что взять в презентацию и материалы Марафона

### Сохранить и усилить

- Собранность как владение вниманием.
- Метафору неваляшки: она точнее объясняет возврат после сбоя, чем призыв «не пропускай».
- Различение объектов и стиля жизни.
- Причинную цепочку «методы → стиль → результаты».
- Состояние как стартовую точку, а не как ярлык личности.
- Минимальный слот без нормативного времени.
- Минимальный рабочий продукт, включая честную рефлексию о непонимании.
- Пять стартовых шагов от наставников.
- Возможность обратиться за поддержкой именно в месте поломки.

### Перестроить порядок первой встречи

Рекомендуемый ход:

1. Представление и единый чат для ответов.
2. Короткий гут-чек состояния.
3. Собранность и модель неваляшки.
4. Системная карта `состояние → роль → метод → продукт`.
5. Объекты будущего и производящий их стиль.
6. Один кейс культуры — без двух длинных исторических отступлений.
7. Минимальный слот и видимый продукт.
8. Пять конкретных стартовых шагов.
9. Проверка: каждый написал состояние, слот и первый продукт.
10. Формат участия и следующий созвон.

Такой порядок быстрее приводит участника к действию и сохраняет главный новый блок про стиль жизни.

### Исправить организационные расхождения перед повторным использованием

1. В презентации указан состав команды из пяти человек; в живом представлении фактически фигурировали ведущий и два наставника. Нужен единый актуальный список.
2. В слайдах описаны «командный под» и «соло-трек»; в завершении встречи разделение прозвучало как самостоятельное бесплатное прохождение через бота и платный общий поток с чатом и встречами. Нужно выбрать одну формулировку продукта.
3. Ведущий просил писать в Telegram, но часть участников писала во внутренний чат Телемоста, который ведущий увидел только в конце. Перед встречей нужно назначить один канал либо выделить человека, который переносит реплики ведущему.
4. Начальный вопрос о состоянии был задуман с возвратом к ответу после раскрытия состояний, но из-за расхождения каналов callback сработал частично. Нужна явная остановка и повторная проверка.
5. Слайд о британском велоспорте присутствовал, но в живой речи ведущий решил не разбирать пример. Для записи нельзя считать его рассказанной частью встречи. Перед следующим потоком либо убрать блок, либо выделить ему время.
6. История Земмельвейса уже используется в материалах первой волны. Если она остаётся, нужно сократить повтор и связать её именно с новой мыслью о масштабе «стиль человека ↔ культура группы».

### Добавить в рабочую тетрадь

Короткую страницу «Мой стиль сейчас»:

| Область | Метод, который уже выполняется автоматически | Какое состояние он производит | Оставить / изменить / проверить |
|---|---|---|---|
| Работа |  |  |  |
| Саморазвитие |  |  |  |
| Отдых |  |  |  |
| Окружение |  |  |  |
| Работа с ИИ |  |  |  |

И карточку возврата:

- Что выбило меня из режима?
- Когда я это заметил?
- Какой минимальный крючок доступен сейчас?
- Какой видимый след подтвердит, что я вернулся?
- Что изменить в среде перед следующим повтором?

## Рекомендуемый порядок дальнейшей работы

1. Сначала исправить организационные расхождения в материалах Марафона.
2. Затем выбрать 3–4 публикационных сюжета: неваляшка, ясность, пять минут в плохой день, работа с ИИ не равна промтам.
3. Отдельно согласовать дополнения к существующим Pack-сущностям; новых сущностей по материалу встречи пока не требуется.
4. После Pack-приёмки встроить причинную карту и журнал возвратов в программу ЛР.
