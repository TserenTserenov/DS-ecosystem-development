# Метод недели 3

**Медленное чтение сложного источника**
**Объясняем — на встрече не проходим**

---

## Выбор источника

- Один сложный источник для **одного конкретного решения** из списка РП недели
- Документация, статья, регламент, чужой код
- Не абстрактный текст «для общего развития»

---

## Медленное чтение с пометками

- Читать с пометками и вопросами, а не пролистать
- Цель — выйти с **конкретным решением**, не с «стало понятнее»
- Критерий готовности: решение объясняется со ссылкой на конкретное место источника

## Рабочее задание на неделю: на что обращать внимание

1. Выберите один сложный источник для одного конкретного решения из списка РП недели
2. Читайте медленно, с пометками и вопросами — цель решение, не «стало понятнее»
3. Продолжайте держать ежедневный слот и распределять бюджет между продуктами списка
4. Список РП недели остаётся живым — отмечайте готовое
5. Если проверяли ограничение и гипотезу на этой неделе — сверьте на следующей встрече, как она сработала
6. На встречу принесите: решение и источник, случай, где чтение заняло больше времени, чем ожидали

# Итог встречи

- **Главное — одно решение, принятое на основе сложного источника,** не общее «стало понятнее».
- Список РП недели живой: критерий готовности у каждого пункта.
- Бюджет слотов распределяем **заранее**, не задним числом.
- Проверка ограничения — одна стадия расхождения, одна гипотеза, не весь конвейер сразу.
- **Ведём список новых понятий** и разбираем их в третьем слоте.
- Следующая встреча — метод недели 4.
