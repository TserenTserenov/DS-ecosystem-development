# Неделя 2 — задание

## Цель недели

Перейти от одного рабочего продукта к короткому списку и научиться распределять на них бюджет времени осознанно, а не по ситуации.

## Метод недели 1: бюджет и учёт проектных слотов

Определите, сколько слотов в неделю реально можете выделить рабочему проекту, и распределите их заранее между запланированными рабочими продуктами (не «как пойдёт», а конкретное число слотов на каждый). Ведите учёт факта против плана: сколько слотов запланировали и сколько реально провели.

## Метод недели 2: лёгкая сессия стратегирования

Проведите короткую сессию (15-20 минут, можно с IWE): что хочу изменить в рабочем проекте на этой неделе, зачем, какой результат нужен, какие рабочие продукты для этого нужны. Это лёгкая версия метода — полная связка «проблема → неудовлетворённость → цель → метод → проект» разбирается позже, на неделе 8 (см. `../00-overview/01-weekly-loop-and-methods.md`). Здесь задача практическая: запустить список, не описать его в совершенстве.

## Метод недели 3: список рабочих продуктов на неделю

По итогам стратегирования запишите список из 2-4 рабочих продуктов на неделю (не один, как на неделе 1). У каждого — короткое название и критерий готовности. По ходу недели отмечайте готовые и, если появляется новый нужный продукт, дописывайте его в список, а не держите в голове.

## Рабочий продукт недели (пример)

Сам список РП недели (с критериями готовности) + минимум один продукт из списка, доведённый до готовности.

## Критерий готовности

Список существует как отдельный артефакт (заметка, не память); распределение слотов по продуктам сделано заранее, не задним числом.

## Свидетельство

После каждого слота — какой продукт из списка продвигали, план/факт по слотам.

## Что принести на встречу

Список РП недели с отметками готовности, факт по слотам против плана, один вопрос по формулировке стратегирования, если она не давалась.
