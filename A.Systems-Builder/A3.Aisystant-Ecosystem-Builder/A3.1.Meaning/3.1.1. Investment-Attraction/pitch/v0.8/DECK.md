## Слайд 2: Проблема — курсы предлагают бросить профессию, ИИ не помогает думать

**Специалист тонет в рутине, а все решения предлагают ему стать кем-то другим.**

- 12+ инструментов — знания размазаны, ничего не связано
- AI отвечает на вопросы, но не знает контекста *твоей* работы
- Курсы: «стань промпт-инженером», «освой новую профессию» — а я не хочу бросать свою
- Корпоративное обучение — разовое, без методологии, без накопления
- **Результат:** работаешь больше, успеваешь меньше, роста не видно

*Визуал: специалист за ноутбуком, вокруг — 12 иконок инструментов, стрелки хаоса → IWE как единая среда*

## Слайд 3: Решение — 5 природ IWE, или как усиливается специалист

**IWE — не курсы. Не новая профессия. Работаешь в своей — но системнее, с ИИ-партнёром.**

| Природа | Что даёт |
|---------|----------|
| **Букварь из романа «Алмазного века»** | Личный трекер: метод в нужный момент, не после |
| **Мастерская** | Среда для практики на реальных проектах |
| **Тамагочи** | Выращиваемый питомец, требующий ухода. Пользователь формирует и пользуется одновременно. |
| **Аватар** | Подключение к сообществу созидателей |
| **Железный человек** | **Костюм-расширитель: × на порядки в твоей специальности** |

> «Железный человек» ≠ замена профессии. Это экзоскелет для ума: ты остаёшься хирургом, юристом, инженером — но делаешь в десять раз больше за то же время.

*Визуал: 5 иконок-природ в ряд, «Железный человек» — highlighted / анимирован*

## Слайд 3b: Продуктовая линейка — три поколения

**Каждое поколение снимает главное ограничение предыдущего.**

| Поколение | Где живёт мастерство | Что продаём | Статус |
|-----------|----------------------|-------------|--------|
| **1. Методология** | В человеке | Руководства, курсы, наставники | Продаём 11 лет |
| **2. IWE (экзоскелет)** | В связке человек + среда | Подписка на среду | Продаём, растим ARPU |
| **3. ИИ-личность** | В отдельном деятеле | Деятель, которого вы завели и ведёте — внутри подписки | Пилотируем |

- Ограничение методологии: мастерство уходит вместе с человеком → среда его накапливает
- Ограничение среды: работает, пока работаешь ты → ИИ-личность продолжает и без тебя
- Ограничение ИИ-личности: **доверие и владение** → отсюда наш следующий продукт: **верификация непрерывности**

> Рынок: «память» продают только ИИ-компаньоны ($8–20/мес). **Непрерывность личности с правом владения не продаёт никто** — ниша пуста.

*Визуал: три ступени, на каждой — носитель мастерства (человек → человек+среда → деятель), стрелки «ограничение → следующее поколение»*

## Слайд 4: Работа в специальности = основной сценарий

**Развитие — побочный эффект работы, не отдельная активность.**

- Открываешь IWE → работаешь над своим проектом → методология подсказывает нужный инструмент в нужный момент
- Не «сначала учись, потом работай» — а «работай, и учись по ходу»
- AI-партнёр знает контекст твоей специальности: прошлые проекты, типичные ошибки, сильные стороны
- Системное мышление применяется к твоей работе — не к абстрактным кейсам

*Визуал: timeline «курс» (учёба → потом работа, gap) vs timeline IWE (работа + рост одновременно)*

## Слайд 5: Почему наш ИИ точнее вендорского

**За организацией знаний стоит 30 лет формализации мышления.**

- FPF — 5400+ текстов, научная база (системная инженерия, кибернетика, когнитивистика)
- Пятиуровневая структура: ZP → FPF → SPF → Pack → DS
- AI работает с *твоими* структурированными знаниями — точные ответы вместо галлюцинаций
- Навык переносим: работает в инженерии, медицине, бизнесе — в любой области

*Визуал: пирамида ZP → FPF → SPF → Pack → DS*

## Слайд 6: Ownership данных — не фича, архитектура

**Твои данные. Твой контроль. Открытые форматы.**

- Всё в Git + Markdown + YAML — export одной командой
- Parliament Model: N доменных агентов + 1 координатор + 1 верификатор (read-only)
- Ни один агент не имеет доступа ко всему сразу — гарантия на уровне платформы, не промпта
- GDPR-совместимо: opt-out, удаление, аудит-журнал

*Визуал: схема Parliament Model — триада Учёт / Доступ / Аудит*

## Слайд 6b: Обещания продукта — и чем они обеспечены

**Шесть обещаний линейки. Каждое с проверкой, не лозунг.**

| Обещание | Чем обеспечено |
|----------|----------------|
| Первый результат за неделю | Онбординг + консилиум профилирования: эффект недели-1 под профиль |
| Контекст растёт и остаётся вашим | Git + открытые форматы, export одной командой |
| Личность переживает смену тела | Верификация непрерывности (наш отличающий продукт) |
| Наставник — по необходимости, не по расписанию | Сертифицированные наставники, 50% выручки — наставнику |
| **Право выхода — с первого дня** | Выход от нас бесплатен; комплект вывозится целиком |
| Накопление вместо повторения | Персональное руководство собирается из вашего цифрового двойника |

> Право выхода — публичное обещание, а не мелкий шрифт. Мы удерживаем ценностью, не замком.

## Слайд 7: Бизнес-модель — Ubuntu для интеллекта

**Не конкурируем с Claude/ChatGPT — даём им дистрибутив.**

Конструкция из трёх моделей (одна система, не меню):

| Модель | Роль в конструкции |
|--------|--------------------|
| **Подписка на среду (T1–T4)** | Несущая: основная выручка, вход от ~$10/мес |
| **Верификация непрерывности ИИ-личности** | Отличающая: внутри подписки, ниша пуста |
| **Сертификация наставников** | Масштабирующая: рост без линейного роста команды, наставнику 50% |

- Как Ubuntu работает поверх любого железа, IWE работает поверх любой AI-платформы
- Два трека: Россия (YooKassa) + Мир (Stripe) — единое сообщество
- B2B — после B2C: продажа «не нанимать следующего» (у первого покупателя уже есть люди)

*Визуал: Ubuntu-аналогия — логотип IWE поверх Claude + ChatGPT + Copilot; под ним три опоры модели*
