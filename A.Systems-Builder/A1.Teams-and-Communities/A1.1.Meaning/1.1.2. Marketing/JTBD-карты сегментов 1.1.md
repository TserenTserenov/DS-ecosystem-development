# JTBD-карты сегментов

## 0. Назначение документа

Этот документ связывает работы-к-выполнению (JTBD, блок 3) основных ЦА с нашими решениями и руководствами; формирует матрицу «запрос → продукт/метод → метрика результата». Полные карточки (JTBD + боли/выгоды + анти-профиль и т.д.) — в [audiences/](audiences/), здесь только сводка блока 3 для быстрой сверки между сегментами.

---

## 1. Сводная матрица «запрос → ответ → метрика»

| Сегмент | Функциональная работа (ядро запроса) | Главный ответ продукта | Метрика попадания |
|---------|----------------------------------------|-------------------------|--------------------|
| [A1](audiences/A1-профессионал-предметник.md) | «внедри систему развития, которую не нужно заводить заново» — усилиться в своей специальности, не становясь айтишником | канон «про специальность» (Вариант 4) + экзокортекс, держащий ритм | доля не-ИТ профессий в наборе волны-2; конверсия марафон → подписка |
| [A2](audiences/A2-ит-профессионал.md) | «ИИ делает мою работу — хочу быть тем, кто им управляет» — встроить метод поверх своего стека, не переезжать | позиционирование «расширение, не замена» (WP-289) + прямой вход в подписку без марафона | конверсия технический-канал (Хабр) → подписка; доля интегрировавших внешний PKM (T4) |
| [K](audiences/K-руководитель-практик.md) | «стану „железным человеком“ сам → подниму мышление команды» — применить в реальных рабочих задачах | короткий нелинейный вход через личный бренд, мост к будущему корп.-продукту (D) | доля руководителей в наборе волны-2; конверсия руководитель → команда (метрика появится с продуктом D) |
| [C](audiences/C-тёплая-база.md) | «покажи, что нового, но не заставляй разбираться с нуля» — реактивация без давления | персонализированный дайджест «что изменилось за N лет» (WP-251) + сигнал фронтира (WP-117) | доля давних подписчиков (>1 года), открывших IWE после дайджеста |
| [L](audiences/L-молодой-специалист.md) | «не вылететь с рынка, не успев закрепиться — расти быстрее, чем сжатие» | дешёвый массовый вход (марафон + подписка низкого чека), растёт с платформой | проверить во 2-м раунде интервью |
| [M](audiences/M-профессиональный-переход.md) | «собрать себя заново, не откатиться в старое» — состояние Поворот | марафон (Поворот) → подписка → программа ЛР под новую траекторию | проверить во 2-м раунде интервью |
| [N1](audiences/N1-предприниматель-среднего-дела.md) | «поднять всю команду дела, а не только себя» | подписка → программа РР → будущий B2B для команды | проверить во 2-м раунде интервью |
| [N2](audiences/N2-основатель-стартапа.md) | «сделать новое — ИИ вместо первых сотрудников, архитектор я» | подписка → резидентура → авторство/мастерская | проверить во 2-м раунде интервью |

**Общее по трём основным профессиональным сегментам (A1/A2/K):** различие не в JTBD-ядре (все хотят усилиться через ИИ, не быть вытесненными), а в (а) готовности к линейному входу (A1/K короче терпят марафон целиком, A2 предпочитает прямой вход) и (б) языке обращения (предметный/деловой/технический — блок 2 «Тон» каждой карточки).

**Гипотезы L/M/N1/N2:** добавлены в карту как сегменты-двери для 2-го раунда интервью; JTBD и метрики пока не проверены.
