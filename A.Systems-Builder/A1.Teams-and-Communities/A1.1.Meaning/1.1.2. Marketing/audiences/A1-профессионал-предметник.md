# A1 — Профессионал-предметник, встраивающий ИИ в свою работу («железный человек»)

## 1. Паспорт сегмента

| Поле | Значение |
|------|----------|
| Идентификатор | A1 |
| Имя сегмента | Профессионал-предметник, встраивающий ИИ в свою работу |
| Статус | кандидат (карточка-черновик, эшелон утверждает пилот в Ф2) |
| Эшелон | основная (предложение) |
| Владелец | пилот + служба продвижения (блок 11) |
| Дата решения о статусе | — |
| Дата следующего пересмотра | — |

## 2. Портрет и адрес

- **Профессиональный адрес:** консультант, менеджер производства/проектов, эксперт, преподаватель, аналитик — любая специальность БЕЗ требования «быть айтишником»; 25-50 лет; калибр от «Я» до «команда». Живые примеры из интервью: консультант по Теории ограничений (30 лет практики, пишет книгу), проектный менеджер молочного завода (отдел трансформации), ИТ-консультант, запускающий свой продукт «чекап поддержки».
- **Психографика:** состояния Хаос / Тупик / Поворот (портрет марафона); «постоянно хочу, но не доходят руки»; страх «ИИ обесценит мою экспертизу» + нежелание переучиваться на программиста.
- **Где обитают:** сообщество и рассылки школы, Telegram-каналы по профессии, рекомендации выпускников (сегмент рекомендателей из интервью), семинары.
- **Размер и платёжеспособность:** ICP посчитан только для практиков с интересом к системному мышлению (~200K потенциальных, RU-рынок); отдельной оценки предметников без ИТ нет данных. Платит сам, средний чек — подписка ~10$/нед (канон «цена доступна массовой аудитории»).
- **Стадия принятия новинок:** ранние последователи; терпят «сырость», если видят метод.

## 3. Работы-к-выполнению

- **Функциональные (цитаты интервью):** «внедри в мою жизнь систему развития, которую не нужно заводить заново каждые три месяца»; «дай инструмент мастера, который снимет рутину и позволит заниматься важным»; «помоги дописать книгу быстрее»; «прокачай мышление так, чтобы применять в реальных рабочих задачах».
- **Эмоциональные:** перестать бояться отставания; ощущение «я управляю ИИ, а не он мной».
- **Социальные:** остаться уважаемым экспертом в своей области в эпоху ИИ; «подняться на хорошее повышение».
- **Контекст найма:** триггер — ИИ пришёл в его отрасль/компанию; смена роли (повышение, свой продукт, книга).
- **Конкуренты за работу:** промпт-курсы, ChatGPT «как есть», коучинг, «ничего не делать» (самый сильный).

## 4. Боли и выгоды → наш ответ

| Боль / желаемая выгода | Чем отвечает продукт |
|------------------------|----------------------|
| «Надо становиться айтишником, чтобы использовать ИИ» | канон «про специальность»: врач остаётся врачом, инженер — инженером; среда делает из него «железного человека» — экзоскелет поверх мастерства |
| Знания есть — применения ноль (Тупик) | рабочие продукты вместо конспектов; ритм и учёт |
| Внимание утекает, система разваливается за 3 месяца (Хаос) | экзокортекс держит ритм без воли: протоколы дня/недели, память, ИИ-напоминания |
| Промпт-курсы устаревают с моделью | способ думать не устаревает: метод + принципы, ИИ как носитель метода |
| Страшно менять направление (Поворот) | траектория через ступени + диагностика + наставник/сообщество |

## 5. Анти-профиль

- НЕ для ищущих кнопку «сделай за меня» (автопилот вместо экзоскелета).
- НЕ для не готовых к рефлексии и учёту времени (портрет «саботирующего» из практикума).
- НЕ для ожидающих готовый корпоративный продукт под ключ (это сегмент D).
- Отсекающие вопросы — наследуются из марафонного портрета (готовность пробовать, осознанность запроса, фокус на своей работе).

## 6. Единица принятия решения

| Роль | Кто | Что ему важно |
|------|-----|---------------|
| Пользователь | сам профессионал | усиление без смены профессии |
| Покупатель | он же | цена массовой доступности, оплата из личных денег |
| Влиятель | рекомендатель-выпускник; иногда работодатель (запреты на внешний ИИ — см. 7б) | доверие, безопасность данных |

## 7. Сценарии использования и «правила эксплуатации» *(заполняется фазой Ф4)*

- 7а. Сценарии «поездок»: нет данных (Ф4).
- 7б. «ПДД» и безопасность: заготовка из интервью — корпоративные запреты на внешний ИИ (обход «личный контур + рабочий контур»), NDA и данные заказчиков, нестабильный доступ к моделям (VPN). Полно — в Ф4.
- 7в. Методы по этапам: нет данных (Ф4).
- 7г. Требования к «водителю»: ориентир «10 долларов и 10 часов в неделю» (ритм стажёра); уточнение — Ф4.

## 8. Путь клиента

- Маршрут: пост/рекомендация → марафон (14 дней) → программа личного развития → подписка → когорта. Каналы: клуб, личный бренд (холодный круг), рассылки.
- Тиры: T0 → T1 (регистрация) → T2 (подписка) → T3 (персонализация); пользы новичка P1-P5 за марафон.
- **Маршрут по осям состояний (модель WP-457):** стартовый профиль — оснащённость 0, увлечённость холодная, компетентность ступень 1 (Случайный); целевой маршрут — увлечённость «холодный → активированный» (марафон), оснащённость «0 → T2» (подписка), компетентность «ступень 1 → 2» (Практикующий).

## 9. Путь в сообществе

- Потребитель → участник клуба → сопроизводитель (кейсы своей отрасли) → наставник для своей профессии.
- Актор экосистемы: стажёр → резидент.
- Даёт сообществу: предметные кейсы за пределами ИТ — доказательство «это не для айтишников».

## 10. Продукты и экономика

- Из 11 типов: подписка (ядро), марафон, когорта с наставником, семинары, записи; позже — мастерские.
- Средний чек: подписка ~10$/нед; юнит-экономика — нет данных (взять из архитектуры подписок при Ф5).

## 12. Валидация и метрики

- **Гипотезы:** (Г1) предметники без ИТ конвертируются в марафон не хуже цифровых; (Г2) канон «про специальность» снимает главное возражение.
- **Метрики:** доля не-ИТ профессий в наборе волны-2; конверсия марафон → подписка.
- **Стоп-критерии:** унаследованы из стратегии — меньше 500 подписчиков к 31 августа → пересмотр сегментов; PMF не подтверждён после 3 когорт → переосмысление сегмента.
