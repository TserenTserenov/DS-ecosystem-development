- [ ] Устное согласие на запись получено ДО начала записи

- [ ] Если планируется цитата наружу (пост, публикация) — повторный вопрос про форму (аноним/инициалы/имя) в момент публикации, не задним числом

## 3. Запись

- [ ] Формат выбран: Zoom / Телемост (с авто-расшифровкой) / локальная запись
- [ ] Для C7 (групповая сессия) — тайминг на участника рассчитан заранее (см. `templates/c7-practice-session.md`)
- [ ] Краткие заметки написаны сразу после (≤30 мин от конца) — фиксируют горячее впечатление, пока не забылось
- [ ] Аудио/видео НЕ коммитится в Git — путь к записи (Drive/локально) отмечен для frontmatter `recording:`

## 4. Транскрипция

- [ ] Источник расшифровки выбран: авто-расшифровка платформы (выгрузить как есть) ИЛИ skill `/transcribe <file>` (MLX Whisper) для чистого аудио
- [ ] Имя файла соответствует конвенции: `YYYY-MM-DD-<class>-<инициалы|g{N}>.md` (process.md §8)
- [ ] Файл лежит в `transcripts/`
- [ ] Frontmatter заполнен по шаблону §8 (`date`, `class`, `participant`, `duration_min`, `interviewer`, `source`, `recording`, `status: transcribed`, `related_wp`)
- [ ] **PII-проверка перед коммитом** (process.md §11, БЛОКИРУЮЩЕЕ): grep по фамилиям-отчествам (`[А-Я][а-я]+ [А-Я][а-я]+(ович|евич|вна|овна)`), по юрлицам (`\bООО\b|\bАО\b|\bПАО\b`) и по whitelist компаний (Mondelez, Wildberries, Ozon, Сбер, Яндекс, Газпром, X5, Магнит, М.Видео и аналогичные)
- [ ] Совпадения найдены → ручной обзор + замена на описательную категорию → повторный grep → только потом коммит
- [ ] Список участников (маппинг инициалы/группа ↔ класс ↔ сегмент) обновлён в `~/IWE/DS-my-strategy/inbox/WP-284-participants.md` (private, НЕ в этом репо)

## 5. Разбор

- [ ] Транскрипт + краткие заметки прочитаны Аналитиком
- [ ] Пройдено по 18 направлениям (process.md §5) — отмечено, какие реально прозвучали (обычно 3-6 из 18 на одно интервью)
- [ ] Для каждого активного направления сформулированы задачи-кандидаты (атомарные «что сделать»)
- [ ] Сводка записана: `analysis/<date>-<инициалы|g{N}>.md` по структуре из `templates/c{N}-*.md` (раздел «Шаблон заметок»)
- [ ] Дословные цитаты сохранены отдельно (язык собеседника, не пересказ)
- [ ] Frontmatter сводки обновлён: `status: analyzed`

## 6. Задачи

- [ ] Каждая задача-кандидат → отдельная строка в `tasks-registry.md` (новые — сверху)
- [ ] Статус новой строки: `pending-review`
- [ ] Маршрутизация выполнена (R14 Заказчик по умолчанию; по «маркетинговому» потоку — Маркетолог; по «продуктовому» — Менеджер продукта; process.md §3, §7):
  - [ ] задача ≤4ч и явно дополняет существующий РП → **новая фаза** (строка в его context file)
  - [ ] задача ≥4ч или со своим lifecycle → **новый РП** (через Ритуал согласования, CLAUDE.md §2 — WP Gate)
  - [ ] задача дублирует уже существующую → **слияние**, ссылка на исходную строку реестра
  - [ ] задача вне текущей стратегии → **отказ** с обоснованием (P-приоритет / horizon / сфера) — строка остаётся в реестре, не удаляется
  - [ ] задача на деле «вопрос», не «действие» → переоформить для следующего Strategy Session
- [ ] Статус строки обновлён: `routed → wp-NNN-Ф{X}` либо `rejected: <причина>`
- [ ] `WP-REGISTRY.md` / `WeekPlan W{N}.md` обновлены, если создана новая фаза или новый РП
- [ ] При закрытии РП, выросшего из задачи интервью, → отметка в `tasks-registry.md` (замыкание петли, process.md §6 Шаг 8)
- [ ] На Week Close сверены метрики §9: интервью/месяц ≥4, lag интервью→транскрипт ≤2д, →сводка ≤5д, →маршрутизация ≤7д, доля маршрутизированных ≥80% за 14 дней

## Инвариант

**Ни одна задача не теряется.** Для каждой строки `tasks-registry.md` есть либо ссылка на РП/фазу, либо явная пометка `rejected: <причина>`. Реестр — единственный source-of-truth по задачам из интервью (process.md §1).

## Режим отказа (когда что-то пошло не по плану)

- Транскрипт >7 дней без сводки → задача попадает в Day Open следующего рабочего дня
- Задача в реестре без маршрутизации >14 дней → автоматически `pending-review` для следующего Strategy Session
- Согласие не получено или отозвано → интервью НЕ используется как материал (ни транскрипт, ни цитаты) — только устные пометки в личных заметках интервьюера, не в артефактах репо
