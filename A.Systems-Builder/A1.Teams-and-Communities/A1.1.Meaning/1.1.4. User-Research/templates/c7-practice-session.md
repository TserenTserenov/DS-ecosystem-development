# Чеклист наставника — C7. Практическая сессия / групповая обратная связь (шаблон WP-284)

> **Формат:** это НЕ интервью 1-на-1. Наставник ведёт группу учеников практикума; каждый участник по кругу рассказывает свой прогресс (по IWE и/или по программе ЛР), наставник даёт обратную связь на месте.
> **Материал для анализа:** несмотря на то что это не интервью, сессия даёт богатый материал по направлениям D4 (методика наставничества), D14 (рабочее развитие), D15-D18 (мировоззренческая дуга, слоты мастерства, характеристики выпускника, форма/содержание практики) — process.md §4-5.
> **Пример:** сессия 2026-05-04 (9-е занятие практикума) — группа `g1` в `WP-284-participants.md` (private).
> **Запись:** аудио/видео сессии (с согласия группы) + структурированные заметки наставника сразу после → `transcripts/YYYY-MM-DD-c7-g{N}.md` (групповой файл — `g{N}` вместо инициалов одного человека, см. process.md §8).

## Чеклист наставника

### До сессии

- [ ] Список участников группы (`g{N}`) сверен с `WP-284-participants.md` (private, не в этом репо)
- [ ] Заметки/сводка прошлой сессии под рукой (если группа собирается не первый раз)
- [ ] Тайминг рассчитан заранее: общее время сессии / число участников ≈ бюджет на человека (+ резерв на общий разговор в конце)
- [ ] Повестка на сессию держится перед глазами: что должно прозвучать от каждого — прогресс / затык / что помогло

### Во время сессии — по кругу на каждого участника

- [ ] Дать каждому рассказать без перебивания первую минуту (свободный формат)
- [ ] Задать 1-2 уточняющих вопроса из блока «Вопросы по кругу» (см. ниже)
- [ ] Дать обратную связь — конкретную, по факту, не общими словами
- [ ] Уложиться в рассчитанный тайминг на человека — не «залипать» на одном участнике за счёт остальных (известный антипаттерн: наставник провёл 10 минут с одним участником на групповой сессии, в ущерб остальным — process.md, Сценарий 1)
- [ ] Зафиксировать хотя бы одну строку заметки сразу, пока говорит следующий участник — не откладывать всё на «после»

### После сессии (≤30 мин)

- [ ] Заполнить структуру заметок по каждому участнику (см. ниже)
- [ ] Отметить кросс-темы — то, что прозвучало у нескольких участников одновременно, это сильный сигнал
- [ ] Задачи-кандидаты → `tasks-registry.md`
- [ ] Если кто-то из группы отдельно созрел на полноценный разговор (класс C1 или C6) — запланировать отдельное интервью, не пытаться добрать вопросы «на бегу» внутри группового формата

## Вопросы по кругу (опора, не сценарий)

Для каждого участника, адаптируя формулировку под контекст:

- Что сдвинулось с прошлой сессии — конкретный случай, не «в целом всё нормально»?
- Где застряли? Что уже попробовали, чтобы сдвинуться с места?
- Что из практики (Day Open/Close, Week Close, слоты мастерства) стало автоматизмом, а что всё ещё требует усилия? (D18)
- Есть ощущение перехода на новый уровень понимания или действия — в чём именно оно проявляется? (D15, D17)
- Что от группы или от наставника помогло бы сейчас больше всего?

## Что НЕ делаю на этом этапе

- Не превращаю групповую сессию в интервью 1-на-1 за счёт времени остальных участников.
- Не выставляю ступень или фазу дуги вслух посреди сессии — это не `/diagnose`, наблюдения идут в заметки, не в `cp_profile` напрямую.
- Не сравниваю участников друг с другом вслух в группе.
- Не пропускаю тихих участников — тайминг по кругу обязателен, даже если кажется, что «он и так всё скажет сам».
