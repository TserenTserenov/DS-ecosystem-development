# Сомнения и затруднения пользователей (Voice of Customer)

Эмпирический реестр голоса ученика: сомнения, затруднения и возражения реальных участников при прохождении развития.

**Двойное назначение:**
- **Главное - развитие.** Материал кормит каталог мемов (ограничивающие убеждения учеников) и работу Навигатора с сопротивлением. Реестр живёт в ядре A (созидатель), потому что это про состояние ученика, а не про рынок.
- **Вторично - маркетинг.** Те же сомнения снимаются в лендинге, FAQ, контенте, работе с возражениями.

Зарегистрирован в каталоге реестров IWE (`docs/registry-catalog.md`, схема кодов `VOC-NNN`).

## Что где лежит

| Файл | Назначение |
|------|------------|
| [Реестр.md](Реестр.md) | Записи `VOC-NNN`: архетип сомнения + разворот + связь с каталогом мемов |
| [Материалы/](Материалы/) | Сырьё: исходные сообщения участников дословно (одно сообщение = один файл) |

Сырьё и записи разведены намеренно: материал это первоисточник (цитаты, контекст), запись это переиспользуемая выжимка. Одно сообщение может дать несколько записей.

## Как пополнять

1. Положить сырое сообщение в `Материалы/ГГГГ-ММ-ДД-краткий-источник.md` (frontmatter: source, channel, anonymized, consent_public_quote, extracted_to).
2. Разложить его на архетипы. Если архетип уже есть в реестре - дописать цитату/источник к существующей записи, не плодить дубль.
3. Новый архетип - завести `VOC-NNN` (следующий свободный номер): категория, цитата, что за этим стоит, разворот, связи.
4. **Маршрутизация в мемы.** Проверить: это ограничивающее убеждение (мем) или обычный вопрос/возражение? Если мем - найти его в каталоге `SA.CAT.001` (PACK-systems-art); нет совпадения - оформить как новый `M-NNN` (буфер находок - реестр WP-333). Проставить связь в разделе «Связь с каталогом мемов».
5. Обновить индексную таблицу вверху реестра.

## Категории-архетипы (растущий словарь)

Сомнения сводятся к повторяющимся архетипам - это рабочий инструмент и для Навигатора, и для контента:

1. **Эффективность / природные данные** - «сработает ли на мне».
2. **Время / долгосрочность** - «где взять время, как совмещать».
3. **Релевантность роли / фундаментальность** - «подходит ли мне, не заменяет базу».
4. **Перенос на среду** - «как влиять на команду без общего языка».
5. **Философия / ценности** - «согласен ли я с установками (агентность и т.п.)».
6. **Риск догмы / идеологии** - «не секта ли это с сильным мировоззрением».

Новые сообщения сначала пытаемся уложить в существующий архетип; не влезает - расширяем словарь.

## Граница: сомнение ≠ мем

Не каждое сомнение - ограничивающее убеждение (мем по D.010). «Нет времени» = мем (M-020). «Не заменяет фундаментальное образование» = по сути верное наблюдение, не мем. Маршрутизировать в каталог мемов только то, что блокирует развитие через ложное убеждение.

## Правила

- **Обезличивание.** Имена и прямые идентификаторы убирать. Поле `anonymized: true`.
- **Согласие на публичную цитату.** Дословная цитата в публичных материалах - только с согласия автора (`consent_public_quote`). Для внутренней работы и перефразирования согласие не требуется.
- **Граница с Pack.** Здесь сырьё и развороты, а не доменное знание. Формализованные мемы живут в `SA.CAT.001` (PACK-systems-art); сюда кладётся связь.
