# Памятка участника: повторить дома после демонстрации 23.08

> v0.2 (21.08). Формат встречи — закрытая демонстрация (ведущий показывает на своём аккаунте), участники повторяют путь дома в своём темпе.

## Что нужно для старта

| Нужно | Стоимость |
|---|---|
| Аккаунт [claude.ai](https://claude.ai), желательно подписка | от 20 $/мес |
| Подписка МИМ «Инженерия интеллекта» | до 1400 ₽/мес |
| Аккаунт GitHub | бесплатно |

## Шаги

1. **Зарегистрируйтесь** на [claude.ai](https://claude.ai), если ещё не сделали этого.
2. **Подключите Aisystant MCP.** В настройках Claude → Коннекторы → добавить `mcp.aisystant.com/mcp` → Connect. Дальше один из двух вариантов, оба нормальные: если вы ещё не заходили в аккаунт МИМ в этом браузере — откроется страница входа, войдите под своим аккаунтом; если вы уже были залогинены на system-school.ru — подключение пройдёт сразу, без отдельного экрана входа.
3. **Подключите GitHub**, когда чат попросит — это нужно для личного репозитория с вашими данными и руководством.
4. **Начните диалог словами, упоминающими IWE** — например: «Хочу настроить свою личную ИИ-среду по IWE». Так модель сразу подхватит нужные инструкции.
5. Дальше среда сама подскажет следующий шаг: создание личного пространства, первую запись, диагностику.

## Первые команды, которые можно попробовать

- «Создай мне личное пространство» — среда развернёт репозиторий-руководство и репозиторий для данных.
- «Я сегодня съел [что] на завтрак» — первая запись личного следа.
- «Пройди со мной диагностику собранности» — до 6 вопросов, среда узнает вашу текущую ступень.
- «Покажи мой баланс баллов» — команда `/points` в Telegram-боте.

## Что важно знать

- Ваши данные остаются в вашем личном репозитории на GitHub — не в общем контуре.
- Сейчас собираются минимальные данные для выработки привычки. Полный контекст, шифрование и расширенные доступы — следующий шаг, не обещание этой встречи.
- Если что-то не подключилось с первого раза — попробуйте ещё раз или напишите в чат поддержки: возможны технические огрехи первого запуска.
