# Сценарий платного семинара «Практический семинар по IWE», 30.08.2026

> v0.1 (23.08, по итогам пир-сессии Kimi+Codex `sessions/2026-08/23/wp514-seminar-3008-functionality/` в DS-my-strategy-dashboard + решения пилота 23.08). Формат: **платный (5000₽), ~90 мин + Q&A, два блока в одном зале** (новички / развивающие среду — различия помечены в шагах).
>
> **Ключевые решения пилота 23.08, на которых построен сценарий:**
> - Подписка «Инженерия интеллекта» в стоимость семинара НЕ входит, покупается отдельно.
> - Самостоятельное создание пространства в зале — только у участников с подпиской; для остальных — показ ведущего + памятка для повторения дома (вариант 3 пир-сессии).
> - Программа — по решению пилота 20.08 (карточка WP-514, Ф4, 6 пунктов).
>
> **Обязательная честная рамка (проговорить в первые 5 минут и в шаге 2):** «Подписка не входит в стоимость семинара. Сегодня все проектируют свою среду руками; разворачивание пространства показываю я, а кто оформил подписку — повторяет у себя сразу или дома по памятке».

**Рамка:** «бот отвечает и забывает — среда накапливает и возвращает» + четыре объекта внимания из поста №217 (канон презентаций 23.08 и 30.08, решение пилота 20.08).

## Что должно быть у участника ДО семинара

- Аккаунт claude.ai (бесплатный) и Telegram; MCP подключён по памятке (~5 мин).
- Домашнее задание недели (рассылаем 24–25.08): 3–5 личных записей-следов (заметка/еда/рефлексия) и черновик карты четырёх объектов внимания. Кто не накопил — работает на обезличенном учебном наборе.
- Опционально: оформленная подписка — для самостоятельного разворачивания пространства.

## С чем участник уходит

- Заполненная карта четырёх объектов (есть / не хватает / следующий шаг).
- Проект собственной команды ролей.
- Свой недельный след, его обобщение и файл «что изменилось в решении».
- Памятка самостоятельного запуска (аккаунт → MCP → «создай пространство» → первый след).
- Понимание, где лежат его данные (его GitHub) и что куда отправляется.
- Один чёткий следующий шаг: подписка + запуск по памятке, либо продолжение проектирования.

## Ограничения на сцене (обязательно)

- **Проговорить честную рамку про подписку дважды**: в открытии и в шаге 2, в момент показа отказа второго аккаунта.
- **Первое сообщение демо-диалога содержит слово «IWE»** — иначе модель может не подключить инструкции (находка живых прогонов, РП406).
- **Не показывать подключение GitHub через `/github`** — запрашивает доступ ко всем приватным репозиториям (РП406 Ф22 не реализована).
- **Не листать паки через поиск знаний** — подписочный фильтр не включён.
- **Не расходовать лимит начислений**: `note_created` — не чаще 2 раз в день; репетиции — с запасного аккаунта, боевой прогон — один раз на сцене.
- Экраны и данные участников в записи — только с их явного согласия; различать демо-данные и реальные данные ведущего.

## Аварийные обходы (подготовить к 27.08)

- Не пришли баллы → показать сложившийся баланс ведущего, проговорить механику; починка после эфира компенсирующей записью.
- Не создался репозиторий на демо → запасной аккаунт №2; дальше — заранее записанный экран.
- Модель неверно маршрутизировала запись → показать исправление как часть цикла (это и есть шаг 4 «проверка»).
- Участник не может войти/нет записей недели → обезличенный учебный набор.
- Задержался webhook оплаты при входе нового участника → ручная выдача доступа по списку оплативших (владелец платежей назначается 24.08).
- Claude/GitHub/Telegram недоступен → локальные копии всех материалов + записанный экран; решение ведущего, предел ожидания 5 минут.

## Готовность (go/no-go 29.08)

Семинар проводится, если: свежий участник получает баллы, а не ноль; реальная оплата даёт чек и доступ (есть возврат и ручное восстановление); программа проходит без экспериментального кода; учебный комплект готов офлайн; полная репетиция с новым человеком (27.08) уложилась во время; назначены ответственные за платежи/поддержку/возвраты. 29.08 — жёсткая заморозка.
