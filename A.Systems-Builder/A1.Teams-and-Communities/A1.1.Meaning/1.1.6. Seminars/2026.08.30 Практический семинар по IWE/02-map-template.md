> v0.1 (25.08, пир-сессия с Codex `sessions/2026-08/25/2026-08-25-15-wp514-seminar-materials-track2/`, ревью 25.08 нашло и исправило: раньше здесь была ссылка на несуществующий «опорный показ для обоих блоков вместе» — в `01-scenario.md` v0.2 такого общего шага нет). Источник рамки — пост №217 «Новая грамотность эпохи ИИ: четыре объекта внимания» (WP-167). Это карта грамотности, не архитектурная схема продукта — на семинаре иллюстрируем примерами, не превращаем в единственно верное устройство IWE.

**Блок / длительность / формат:** Блок 1, шаг 1 (15 мин, самостоятельное заполнение, аудитория новичков). **Ожидаемый результат участника:** заполненная карта на бумаге/в заметке — 4 строки, для новичка минимум одна отметка «следующий шаг» в правой колонке.

**Решение 25.08 (закрывает прежний открытый вопрос про Блок 2 без Блока 1):** участник, пришедший сразу в Блок 2, не проходит отдельное знакомство с картой — таблица ниже уже содержит однострочное определение каждого объекта в колонке «Определение», этого достаточно, чтобы сразу ответить на «вопрос на разрыв» ниже без предварительного заполнения строк «что есть / чего не хватает». Блок 2 шаг 0 (5 мин) остаётся только сверкой пространства, отдельное время на карту не выделяется.

## Как заполнять

Разная глубина для разных блоков:

- **Новички (Блок 1):** быстро заполнить все 4 строки — что уже есть, чего пока нет — и выбрать ОДИН следующий шаг (не четыре сразу).
- **Продвинутые (Блок 2):** искать разрыв *между* объектами — например, правила накопились, а хранилище для них разрозненное; или хранилище есть, но общих правил (навыков) с ИИ пока нет ни одного явного.

Примеры Дмитрия — только подсказки ведущего рядом с определением, не образец для копирования в свою карту. Участник заполняет карту своей ситуацией, не чужой.

## Для продвинутых — вопрос на разрыв

После заполнения строк ответить одним предложением: *«Между какими двумя объектами у меня самый большой разрыв — то есть один уже сильный, а сосед с ним ещё не связан?»* Это и есть кандидат на следующий элемент среды, который стоит выбрать в упражнении «Своя команда ролей» (`03-roles-questionnaire.md`).
