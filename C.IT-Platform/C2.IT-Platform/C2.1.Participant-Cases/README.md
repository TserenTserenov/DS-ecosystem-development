# Кейсы участников марафона и программ IWE

Живые истории людей, которые применили методы IWE и изменили результаты.

## Назначение

Собирать, структурировать и публиковать кейсы реальных участников — доказательства того, что методы работают. Источники:
- Финальные встречи когорт (как участники рассказывают о своих сдвигах)
- Интервью наставников и инструкторов
- Личные истории в чатах сообщества
- Feedback и опросы после завершения программы

## Структура кейса

```yaml
case_id: "marathon-2026-06-XXX"  # ID участника или порядковый номер
date_collected: "2026-06-18"       # Когда собрали кейс
source: "marathon-closing-meeting" # Откуда взяли: встреча, интервью, чат...
participant_name: "Фамилия И."     # Или просто инициалы (конфиденциальность)
program: "Marathon-v2"             # Какую программу проходил
duration: "14 days"                # Сколько длилась программа
```

**Секции кейса:**

1. **Исходное состояние** (Хаос/Тупик/Поворот) — где был участник в начале
2. **Метод/Практика** — какой конкретный метод применил (письмо, трекинг, целеполагание и т.д.)
3. **Сдвиг** — что произошло, какой результат
4. **Прямая цитата** — одна сильная цитата участника (если есть)
5. **Артефакт** — что создал участник (РП, список, план)

## Примеры локаций

```
C2.1.Participant-Cases/
├── README.md (этот файл)
├── marathon-2026-06-cases.md (кейсы из финальной встречи марафона)
├── marathon-early-adopters.md (кейсы участников из первых когорт)
└── templates/
    └── case-template.md (шаблон для новых кейсов)
```

## Публикация

Кейсы используются в:
- Маркетинговые посты (социальные сети, сайт)
- Страница успеха (landing page программы ЛР)
- Вводные материалы для новых когорт
- Доказательства для доноров и партнёров

## Конфиденциальность

- Имена: инициалы или псевдонимы (если участник согласился — полное имя)
- Деньги: не раскрываем
- Личное: убираем идентифицирующие детали
- Цель кейса > конфиденциальность (но спрашиваем согласие перед публикацией)
