# ADR: Расширение Онбордера на T0 + deprecated DP.SC.169

## Контекст

DP.SC.169 (conductor-lite) — conversational Q&A для T0/T1-пользователей о тирах и следующем шаге — был отдельным артефактом под DP.ROLE.013 (Проводник). WP-406 Ф7 (peer-сессия + ArchGate, 2026-06-10) поставил вопрос: нужна ли отдельная роль для T0/T1 Q&A или её поглощает Онбордер?

## Решение

**Вариант Б принят:** Онбордер (DP.ROLE.067) расширяется на T0. DP.SC.169 deprecated.

## Обоснование (ArchGate PASS)

Три ключевых аргумента:

1. **T0→T1 — бесплатный переход (setup, не оплата).** Тариф начинается только с T1→T2. Поэтому T0-guidance не связан с pricing-механикой → нет coupling с тарифными изменениями → ⚠️ Эволюционируемость снята.

2. **T0-guidance = часть X2 (понимание сообщества).** «Как зарегистрироваться» — это и есть понимание того, как войти в сообщество. Одна причина изменения роли → SRP не нарушен → ⚠️ Современность снята.

3. **«Одно окно для новичка» (позиция пилота).** Онбордер — единственный контакт нового человека с платформой от T0 до Первокурсника. Это ожидаемая ментальная модель → ⚠️ Обучаемость снята.

## Затронутые артефакты

| Артефакт | Изменение |
|----------|-----------|
| DP.ROLE.067 | type: agential; scope: T0+; добавлен T0-Phase в §1, §2, §3; TierUpgraded event в §10 |
| DP.SC.170 | version: 3; scope: T0+; добавлен SC-0; updated sibling → deprecated DP.SC.169 |
| DP.SC.169 | status: deprecated; note: поглощён Онбордером; сохраняется как архивный артефакт |
| DP.ROLE.013 | type: infrastructure-agent; kind: FSM-executor; deprecated §9 (conversational mode) |
| 01B-distinctions | Добавлен DP.D.125: конвенция `infrastructure-agent` vs стратегическая роль |

## Граница T0-scope для Онбордера

- ✅ Setup-guidance: как зарегистрироваться, что сделать первым
- ✅ X2 orientation: что такое сообщество, роли, нормы  
- ✅ X3 trajectory: диагностика + выбор курса
- ❌ Ценовые вопросы (T1→T2 стоимость подписки) → DP.SC.167 Hermes ≥ T3 или прайс-лист

## Follow-up задачи

1. Проверить роутинг R46 / DP.SC.161 для T0-пользователей (ранее шли через DP.SC.169).
2. Зафиксировать `TierUpgraded` domain event в спецификации РП349.

## Отклонённые варианты

**Вариант А** (сохранить DP.SC.169 отдельно, Онбордер с T1+) — отклонён после уточнения пилота о T0→T1 = бесплатный setup. При этом условии нет веских архитектурных оснований для отдельного артефакта.
