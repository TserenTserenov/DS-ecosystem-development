# Рабочая копия `security-posture.md` откатилась к более старому содержимому, чем опубликованная история

**Что:** во время пир-сессии по РП-7 (блок BAK, резервное копирование) агент заметил, что `C.IT-Platform/C2.IT-Platform/C2.2.Architecture/security-posture.md` в рабочей копии репозитория (незакоммиченное состояние) содержит более старую версию содержимого, чем последний опубликованный коммит. Конкретно пропадает вся запись об аудите от 10.09.2026 (`f8d4905f docs(WP-212): security audit 2026-09`): секция «Аудит 2026-09-10», строка в таблице истории аудитов, актуальные даты `updated`/`next_audit` в frontmatter — всё откатывается к состоянию примерно на уровне 15.07.2026. Одновременно строка сгенерированного скриптом раздела покрытия (`COVERAGE-SYNC`) в этой же незакоммиченной копии показывает БОЛЕЕ НОВУЮ метку времени (15.09), чем в опубликованной версии — то есть откат не тотальный, а частичный/смешанный, что не похоже на простой `git checkout` старого коммита.

**Когда обнаружено:** 2026-09-15, ~20:10 МСК, в ходе пир-сессии `2026-09-15-20-wp7-techdolg-razbor` (Claude+Kimi). Не выяснено, когда сама рабочая копия оказалась в этом состоянии — файл не трогался этой сессией.

**Канал:** обнаружено чтением `git diff`/`git log` рабочей копии репозитория `DS-ecosystem-development` на этой машине, не через инструмент агента с прямым доступом к секретам.

**Гипотезы (не проверены до конца):**
1. Прерванный/неудачный merge или rebase, оставивший файл в смешанном состоянии.
2. Ручное копирование старой версии файла поверх текущей (например, восстановление из локального бэкапа) без последующего коммита.
3. Параллельный агент/сессия читал старую версию файла в момент, когда где-то ещё шла генерация COVERAGE-SYNC секции, и записал результат поверх актуального содержимого, сохранив только новый таймстамп.

**Blast radius:** файл — единственный источник дашборда безопасности РП-212 (`status: active`, `owner: WP-212`). Если рабочая копия будет закоммичена как есть — потеряется документированная запись независимой проверки от 10.09 (включая подтверждённые находки: закрытие двух находок WP-458, новая находка про `enforce_admins=false` на `knowledge-mcp`/`digital-twin-mcp`).

**Что не сделано намеренно:** содержимое файла не тронуто и не закоммичено этой сессией — решение (восстановить, отбросить локальные изменения, либо это чьё-то намеренное действие) требует владельца РП-212.

**Что дальше:** владельцу РП-212 — открыть `git diff` на этот файл в рабочей копии, решить: отбросить локальные изменения (`git checkout -- <файл>`, если это случайный откат) или закоммитить сознательно (если правки — часть активной работы, которую эта заметка ошибочно приняла за регресс).
