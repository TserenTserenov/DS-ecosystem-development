# Ложный триггер P5-детектора на описательной фразе

## Симптом
Детектор сработал на фразу из пересказа транскрипта встречи:
«агент получает доступ только к разрешённому подмножеству»

## Ожидаемое поведение
P5 должен триггерить только на явные запросы разрешения у пользователя: «хотите?», «продолжить?», «записать?», «применить?».

## Фактическое поведение
Сработал на описательное предложение без вопросительного знака и без обращения к пользователю.
