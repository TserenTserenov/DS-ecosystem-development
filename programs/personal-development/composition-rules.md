# Правила композиции: Личное Развитие (PD)

## Условия применимости

Программа PD применима ко всем пилотам по умолчанию.
Для пилотов с МШС-квалификацией «Работник» и выше — PD служит **базовым слоем** поликорневой композиции (ЛР-база + РР/ИР-фокус).

## Композиционные правила

1. **Базовый слой:** stage-seed из `seed_lookup` текущей ступени.
2. **Доменный слой:** domain-seed из `domains_applicable` по профилю пилота.
3. **Методический слой:** bottleneck → methods из `bottleneck_to_methods`.
4. **Нарративная дуга:** `narrative_phase` из `PD.FORM.087`.
