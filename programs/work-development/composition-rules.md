# Правила композиции: Рабочее Развитие (WD)

## Условия применимости

Программа WD применима к пилотам с:
- МШС-квалификацией «Работник», «Стратег», «Специалист», «Практик», «Реформатор», «Революционер».
- Работой в команде с явной координацией.

## Композиционные правила

1. **Базовый слой:** stage-seed из `seed_lookup` текущей ступени (структурный аналог из ЛР).
2. **Доменный слой:** domain-seed из `domains_applicable` (domain-knowledge-worker как default).
3. **Методический слой:** bottleneck → methods из `bottleneck_to_methods` (работные адаптации методов ЛР).
4. **Нарративная дуга:** `narrative_phase` placeholder — требует формализации (WP-329).
