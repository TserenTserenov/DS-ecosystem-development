# Правила композиции: Исследовательское Развитие (RD)

## Условия применимости

Программа RD применима к пилотам с исследовательской деятельностью.
Для пилотов с МШС-квалификацией ≥ 2 — RD служит **фокусным слоем** поликорневой композиции (ЛР-база + ИР-фокус).

## Композиционные правила

1. **Базовый слой:** stage-seed из `seed_lookup` текущей ступени (структурный аналог из ЛР).
2. **Доменный слой:** domain-seed из `domains_applicable`.
3. **Методический слой:** bottleneck → methods из `bottleneck_to_methods` (исследовательские адаптации).
4. **Нарративная дуга:** `narrative_phase` placeholder — требует формализации.
